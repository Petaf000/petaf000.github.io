A Unity SDK that turns phones into second-screen controllers.

  • Works with the code you have

    Each phone shows up as a standard Input System gamepad, and touches arrive as normal uGUI events.

  • A picture for each player

    Send a camera’s view to one player’s phone only, like a private map or a zoom lens.

  • Just your Wi-Fi

    Players scan a QR code with the PadPlay app. The PC and the phones talk directly, with no server and no account.
