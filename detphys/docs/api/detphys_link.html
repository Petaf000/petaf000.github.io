detphys_link.hconnection interface and room codes (version 1)

The layer that finds the other player and connects (8. Transports and room codes). It gives you a detphys_transport to pass to the session.

FunctionDescription
detphys_link_abi_versionThe version of this header (DETPHYS_LINK_ABI_VERSION)
detphys_link_createCreates a link from an implementation table (detphys_link_vtable), to plug in your own transportUsage: Transports and room codes › Writing your own transport (your own server, ...)
detphys_link_destroyDestroys it (leaves the room)
detphys_link_transportGets the transport to pass to the session (the link counts what is sent and received)Usage: Transports and room codes › Usage (the same for every transport)
detphys_link_pollCall every frame. Returns the current stateUsage: Transports and room codes › On the game side
detphys_link_room_desc_defaultDefault room settings
detphys_link_hostCreates a room (become the host). The room code is made, or yours is usedUsage: Transports and room codes › Usage (the same for every transport)
detphys_link_joinJoins a room with a room code (become the guest). Typos are returned before any trafficUsage: Transports and room codes › Usage (the same for every transport)
detphys_link_closeLeaves the room
detphys_link_waitWaits until something can be received (headless tests)
detphys_link_get_infoState, role, path, reason, counters, room code
detphys_link_errorText for the last failure (with NULL, why creating failed)Usage: Transports and room codes › States and reasons
detphys_link_state_name / detphys_link_reason_nameASCII names of states and reasons (translation keys)Usage: Transports and room codes › States and reasons
detphys_room_code_makeMakes a room code (six digits) from a seed
detphys_room_code_parseChecks typed text and normalizes it to six digits (skips full-width digits and separators; format error / check digit error)Usage: Transports and room codes › Room codes
detphys_link_create_udpA link over UDP (detphys_udp.h). The role is chosen at creationUsage: Transports and room codes › Transports that come with DetPhys
detphys_link_create_loopbackA link wrapping one side of a loopbackUsage: Transports and room codes › Transports that come with DetPhys
detphys_link_hub_desc_defaultDefault test lobby settings
detphys_link_hub_create / detphys_link_hub_destroyCreates / destroys a test lobbyUsage: Transports and room codes › Transports that come with DetPhys
detphys_link_hub_pumpAdvances the test lobby's time by oneUsage: Transports and room codes › Transports that come with DetPhys
detphys_link_hub_room_countThe number of rooms now
detphys_link_create_hubCreates a link to the test lobbyUsage: Transports and room codes › Transports that come with DetPhys
StructDescription
detphys_linkA link (opaque)Usage: Transports and room codes › Usage (the same for every transport)
detphys_link_room_descRoom settings (members, bucket, room code, seed for making a code, timeout)Usage: Transports and room codes › Room codes
detphys_link_infoState, role, path, reason, round trip, datagram limit, largest datagram sent, counters, kind, room code, descriptions of the other side and yourselfUsage: Transports and room codes › Room codes
detphys_link_vtableAn implementation table (send, recv and get_info are required; poll, host, join, wait, error, close and destroy are optional)Usage: Transports and room codes › Writing your own transport (your own server, ...)
detphys_link_hubA test lobby (opaque)
detphys_link_hub_descTest lobby settings (time per operation, room limit, path to report, datagram limit, per-room transport)Usage: Transports and room codes › Transports that come with DetPhys
