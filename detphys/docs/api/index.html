API reference (C ABI)

The core C ABI is the C headers below (2D is detphys_*, 3D is detphys3d_*). The engine layers call these functions too. Common conventions:

Headers

detphys.hworld, step, hash, workers, snapshots (version 2)21
detphys_body.hbodies, shapes, readback for drawing (version 2)23
detphys_turn.hturn-based sessions, transport interface, loopback (version 9)67
detphys_rt.hreal-time rollback sessions (version 8)54
detphys_kinematic.hmoving concave shapes (version 2)22
detphys_debug.hdesync debugger (version 3, recording format DNDR 2, bundle DNDB 1)32
detphys_udp.hUDP transport for LAN11
detphys_link.hconnection interface and room codes (version 1)28
detphys_relay.hconnecting through your own relay (version 1)4
detphys_eos.hEOS P2P transport (version 2)7
detphys_bake.hconcave shape baker (version 1)13
detphys_rule.hppC++ helper for writing rules (header only)
detphys3d.h3D world, bodies, convex hulls, snapshots, transfers (version 2)48
detphys3d_kinematic.h3D moving concave shapes (version 1)23

Common conventions

  • Structs contain only fixed-width integers, floats and function pointers, with no implicit padding (C# StructLayout.Sequential reads them as is).
  • Structs with struct_size must have it set to sizeof. Fill settings with *_default before changing them.
  • Errors are return values (DETPHYS_OK = 0, negative = DETPHYS_ERR_*). Variable-size data (snapshots, recordings, bundles) is written into caller buffers; if a buffer is too small the call returns DETPHYS_ERR_CAPACITY with the needed size.
  • All values going in are integers (length mm, angle mrad, speed mm/s, force mN, impulse mN·s, materials × 1000; 3D orientations are integer quaternions).
Return valueMeaning
DETPHYS_OK (0)Success
DETPHYS_ERR_ARGUMENT (−1)NULL, out of range, wrong struct_size
DETPHYS_ERR_CAPACITY (−2)Caller buffer too small (*out_size holds the needed size)
DETPHYS_ERR_FORMAT (−3)Snapshot or recording has the wrong format or is broken (the world is unchanged)
DETPHYS_ERR_BASE (−4)The base of a dyn snapshot is missing (the world is unchanged)
DETPHYS_ERR_CORRUPT (−5)Restoring failed half way (destroy and recreate the world)
DETPHYS_ERR_INTERNAL (−6)Allocation or thread creation failed
