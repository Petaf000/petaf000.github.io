detphys3d_kinematic.h3D moving concave shapes (version 1)

This header brings the ideas of the 2D detphys_kinematic.h to 3D worlds (detphys3d.h). It only adds things; the functions and versions of the other headers did not change (the calls that pass a table to 3D sessions are in this header too). The table settings (detphys_kinematic_desc), statistics (detphys_kinematic_stats), segment easing (DETPHYS_EASE_*), motion flags (DETPHYS_MOTION_*) and session flags (DETPHYS_KINEMATIC_SESSION_*) are the 2D ones. Values are integers in mm, mrad, mrad/s and ticks; orientations are integer quaternions. See 3. Concepts for the ideas and usage.

Type: detphys3d_motion_fn (the shape of a CALLBACK motion function: receives user, the body ID and the tick, writes the pose and returns 0; negative = failure).

Constants: DETPHYS3D_KINEMATIC_ABI_VERSION (1), paths DETPHYS3D_PATH_FIXED (0), DETPHYS3D_PATH_PINGPONG (1), DETPHYS3D_PATH_ORBIT (2), DETPHYS3D_PATH_POINTS (3), DETPHYS3D_PATH_CALLBACK (4).

  • One tick (the same on every peer and during re-simulation): update (at the start of the tick; skipped with NO_PRE_UPDATE) → the rule's apply_inputs (apply_input in turn-based play) → detphys3d_kinematic_step (with NO_SPLIT: detphys3d_world_step → update) → after_tick.
  • Keep the table alive longer than the session, and make one per peer and per session (the session does not copy it; do not share it with other worlds).
  • The table's split settings, flags and motions (its contents after begin) are part of the config check, so peers with different motions do not connect. Sessions without a table keep the same check values as before.
  • Change the table (add / bind / unbind / clear) only inside begin (begin_match). The table is not rolled back; to change a motion during a match, make the motion itself a function of the tick (stops with POINTS, or CALLBACK computing from the tick).
  • Nothing is needed after a rollback (snapshot restore): the snapshot holds the function's values. The table is in neither the snapshot nor the state ring.
  • Structs contain only fixed-width integers and pointers, with no implicit padding on 64-bit.
