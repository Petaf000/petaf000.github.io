detphys_debug.hdesync debugger (version 3, recording format DNDR 2, bundle DNDB 1)

Version 3 added recordings of 3D worlds (detphys3d.h); it only adds things.

  • reserved in the recording settings detphys_debug_config was renamed to dimensions (0 or 2 = 2D, 3 = 3D; left at 0 everything works as before).
  • 3D recordings are written in format 2. 2D recordings are still format 1 and their bytes are the same as in version 2. Comparing a 2D recording with a 3D one returns DETPHYS_ERR_FORMAT.
  • 3D sessions (detphys_rt_create3d, detphys_turn_create_rule3d) accept detphys_rt_set_debug / detphys_turn_set_debug too (the rt and turn versions did not change, so check detphys_debug_abi_version() >= 3).
  • In 3D, box2d_hash, box2d_first_tick and DETPHYS_DEBUG_REC_BOX2D_HASH hold Box3D's state hash (the same value as detphys3d_world_engine_hash). The names are kept from 2D.
