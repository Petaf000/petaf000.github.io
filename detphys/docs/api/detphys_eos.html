detphys_eos.hEOS P2P transport (version 2)

A connection interface over Epic Online Services P2P. It is in a separate library, detphys_eos (Windows and Android; it loads the EOS SDK, which comes from Epic). For usage and the Android / iOS setup, see "EOS P2P" in 8. Transports and room codes.

FunctionDescription
detphys_eos_abi_versionVersion of this header (DETPHYS_EOS_ABI_VERSION)
detphys_eos_sdk_versionVersion string of the loaded EOS SDK (to check where the SDK is and that it links)
detphys_eos_desc_defaultDefault settingsUsage: Transports and room codes › EOS P2P
detphys_eos_link_createCreates an EOS transport (detphys_link). The first one initializes EOS and starts logging in with a device ID (the login continues inside detphys_link_poll, so you can call detphys_link_host / detphys_link_join without waiting). One at a time per processUsage: Transports and room codes › Transports that come with DetPhys
detphys_eos_last_errorWhy the last detphys_eos_link_create failed ("" if it did not)Usage: Transports and room codes › EOS P2P
detphys_eos_shutdownShuts EOS down. Call it once at the end of the process (if a transport still exists it does nothing and returns DETPHYS_LINK_E_STATE; afterwards no more EOS transports can be created in the same process)Usage: Transports and room codes › EOS P2P
StructDescription
detphys_eos_descDeveloper portal values (product ID, sandbox ID, deployment ID, client ID and client secret), product name and version, the name used to log in, cache folder, socket name, login timeout, log level, relay mode, flagsUsage: Transports and room codes › EOS P2P

Constants: datagram limit DETPHYS_EOS_MAX_PACKET (1170); relay modes DETPHYS_EOS_RELAY_* (ALLOW = default, FORCE, NEVER); flags DETPHYS_EOS_FLAG_NEW_DEVICE_ID (for the second process when testing two players on one machine; do not use it in a game).
