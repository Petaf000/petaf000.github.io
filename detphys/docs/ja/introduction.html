概要

#DetPhys とは

同じ設定と同じ入力なら、どの端末・どのエンジンでもビットまで同じ結果になる物理と、それを使ったネットコード（ターン制とリアルタイム・ロールバック）です。Windows と Android、Unity と Godot と Unreal の間で、同じ試合を同じ値で進められます。

  • 送るのは入力だけです。リアルタイムで 1 tick あたり片方向 32〜48 バイトです。
  • 毎 tick（ターン制は毎ターン）、状態のハッシュを相手と比べます。desync したらすぐ分かり、ホストの状態で自動で直ります。
  • desync した時は desync デバッガーが、どの tick の・どのボディの・どの値が・何 ULP ずれたかと、原因が入力か物理かを示します。
  • 凹形状（歯車・U 字・くし・生き物のシルエットなど）は、画像から凸多角形の組にして、近似せずに当たり判定に使えます。
  • 動く凹形状（回る歯車・往復する足場・リフト）は tick の関数で動きます。ロールバックしても同じ値を作り直します。
  • 2D（Box2D v3）と 3D（Box3D）のどちらのワールドも、同じセッションに載せられます。
  • コアは C++ で、C ABI で公開しています。Unity・Godot・Unreal の層は、同じビルド済みのコア（detphys_core）を呼ぶ薄い層です。

#どんなゲームに向くか

  • 形を交互に落として積み上げる積み上げ対戦（ターン制）
  • 物理で押し合う・投げ合うアクションや、プラットフォーム対戦（リアルタイム、入力遅延 0）
  • 回る歯車や動く足場の上で戦うアクション（動く凹形状）

#できること

機能中身
決定論の 2D 物理Box2D v3.2.0 の上のワールド。入力は全部整数。tick ごとの状態のハッシュ
決定論の 3D 物理Box3D の上のワールド（detphys3d.h）。箱・球・カプセル・凸包。向きは整数の四元数
ターン制のセッション2 人が交互に入力を出す。desync したらホストの状態で再同期。再接続・ホストの再起動から続ける。2D と 3D。組み込みのルール「積み上げ」
リアルタイムのセッション入力遅延 0（既定）のロールバック。予測の上限 N（既定 10）。入力遅延の自動調整（既定 OFF）。再同期・再接続。2D と 3D。ルールは C / C++ / C# / GDScript で書ける
組み込みのルール「押し合い」2 人が箱と凹形状を押し合うリアルタイムのルール（2D は detphys_rt_create_push、3D は detphys_rt_create_push3d）。回る歯車・往復する足場・上下する U の「動くステージ」も選べる。2D は 3 つのエンジンのどれからでも、3D は Unity と Godot の間で、互いに対戦できる
動く凹形状回る・往復する・円を回る・点をたどる・コールバックの 5 つの動き。速い tick だけ分割して、すり抜けを防ぐ。2D（detphys_kinematic.h）と 3D（detphys3d_kinematic.h）
凹形状のベイカーエディタの中で（Unity: Window > DetPhys > Shape Baker、Godot: DetPhys Shapes ドック、Unreal: テクスチャを右クリック > Bake DetPhys Shape）、画像から凸多角形の組（.dnshape、mm の整数）を作る。どのエディタでも同じバイト列。分解は Steiner（既定）と Hertel-Mehlhorn
desync デバッガーセッションに組み込み（既定 OFF、2D と 3D）。desync したら両方のピアが同じ報告を持つ。両方の記録を 1 つのファイル（バンドル）にして、開発者に送ってもらえる
トランスポート差し替えられる API（送る・受け取るの 2 つの関数）と、「ルームを作る・ルームコードで入る」 API（detphys_link.h）。LAN 用の UDP・自分のサーバーに置くリレー（detphys_relay）・1 プロセスのループバックが付く。EOS P2P（Epic Online Services。EOS の SDK は Epic から入手）は Unity・Godot の Windows・Android と Unreal の Windows で使える
ワーカー1〜64 本（既定 1）。本数を変えてもハッシュは変わらない。エンジンのジョブの仕組みも渡せる
  • 1 つのセッションは 2 人（ピア 0 と 1）です。
  • ネット越しには、EOS P2P（EOS P2P。自分のサーバーは要りません）か、自分のサーバーに置くリレー（8. トランスポートとルームコード）で対戦できます。ほかのトランスポートも detphys_transport に差し込めば使えます。

#このバージョンに入っていないもの

どれも予定です（入るバージョンはまだ決めていません）。

  • Steam のトランスポート。 Steam では、自分のトランスポートを detphys_transport に差し込むか、EOS P2P か自前のリレーを使ってください。
  • iOS の EOS P2P（Unity・Godot）と Unreal の Android の EOS P2P。 そこでは LAN の UDP と自前のリレーが使えます。
  • Unreal の iOS と、macOS のエンジンの層。macOS 用のライブラリは Unity のパッケージに入っていますが、Unity の Mac のエディタ・プレイヤーではまだ試していません。
  • Unreal の 3D の desync デバッガーと、全部の機能の Blueprint のノード。 Unreal では、一部の機能を C++ からコアの C ABI で使います（エンジンごとに使えるもの）。
  • wasm。

#やらないこと

  • 物理エンジンの完全な自作はしません。 物理は Box2D v3 / Box3D です。
  • 物理で自由に動く凹メッシュどうしの三角形の判定はしません。 凹形状は凸多角形の組で表します。動く凹形状は、決めた動きで動くキネマティックです。
  • サーバーの運営はしません。 片方が待ち受け、もう片方がつなぐ P2P です。ネット越しは、EOS P2P・自前のリレー・ほかのトランスポートを使います。
  • 絵や音楽の素材は入っていません。 サンプルの形は手続き的に描きます。

#バージョンの数え方

コアの C ABI は、ヘッダーごとにバージョンを数えます。関数を足しただけなら、バージョンが上がっても古い関数はそのまま使えます（起動時に >= で比べます）。

#3D について

3D（Box3D）は、ワールド（detphys3d.h）・ターン制（detphys_turn_create_rule3d）・リアルタイム（detphys_rt_create3d）・動く凹形状（detphys3d_kinematic.h）・desync デバッガーまで使えます。PC の 5 つのビルドと Galaxy S9 で全 tick 一致し、PC と S9 の対戦（取りこぼし・わざとずらす・再接続・ホストの再起動）でも一致しました。使い方は 3. コンセプト、関数は 7. API リファレンス の detphys3d.h にあります。

  • 3D で回る台の上に載せた物は、外へゆっくり滑ります（Box3D の接触の性質。3. コンセプト）。
  • 再同期で送る状態は、115 体で 190〜260 KB です。

#ライセンス

  • DetPhys は Box2D・Box3D とは無関係で、Box2D・Box3D およびその作者（Erin Catto）に公認・推奨されたものではありません。
  • DetPhys の配布物には THIRD_PARTY_NOTICES.md（Unity のパッケージは Third Party Notices.md）が入っています。配るゲームにも、その中の著作権表示とライセンス文を残してください。
  • Unity で書き出したゲームには、DetPhys のパッケージがこのファイルを自動で入れます。Windows は実行ファイルの隣と <名前>_Data/StreamingAssets/ に DetPhys/THIRD_PARTY_NOTICES.md、Android は APK の assets/DetPhys/THIRD_PARTY_NOTICES.md、iOS は Xcode プロジェクトの Data/Raw/DetPhys/ に入ります。
  • Godot で書き出したゲームには、DetPhys の GDExtension がこのファイルを自動で入れます。書き出したゲームのデータの addons/detphys/THIRD_PARTY_NOTICES.md に入り、Windows・Linux は実行ファイルの隣の DetPhys/THIRD_PARTY_NOTICES.md にも入ります。エディタのプラグイン（DetPhys）を有効にしていなくても入ります。
  • Unreal でパッケージしたゲームには、DetPhys のプラグインがこのファイルを自動で入れます。Windows はゲームのフォルダの中、プラグインの場所に合わせた所（例 RemappedPlugins/DetPhys/THIRD_PARTY_NOTICES.md）、Android は APK の assets/DetPhys/THIRD_PARTY_NOTICES.md に入ります。
  • Box2D v3.2.0（MIT、Copyright (c) 2022 Erin Catto）: ロールバック用の snapshot / restore の API を足してあります（今ある API と動作は変えていません）。
  • Box3D（MIT、Copyright (c) 2026 Erin Catto。main のコミット 3362633 に固定）: ロールバック用の snapshot / restore の API を足してあります。同梱の rapidhash・verstable・qsort.h のライセンスも同じファイルにあります。
