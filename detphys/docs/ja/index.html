同じ入力なら、どの端末でもビットまで同じ物理

物理が遊びの中心にある対戦・協力ゲームのための、2D と 3D の決定論の物理と、ロールバック・ターン制のネットコードです。送るのは入力だけ。desync したら、どの tick のどの値かを示します。Unity・Godot・Unreal が同じコアを呼びます。

クイックスタートできること

    2022.3 LTS 以降

    Unity で始める

  • Godot

    4.3〜4.8

    アドオン addons/detphys（GDExtension と C#）

    Godot で始める

  • Unreal Engine

    5.4〜5.8

    プラグイン DetPhys 0.1.0（ベータ）

    Unreal で始める

エンジンをまたいで対戦できます（Godot と Unity、Unreal と Unity、Unreal と Godot）。

実測値

項目値条件
同じハッシュWindows x64・Android arm64・iOS arm64MSVC・clang-cl・MinGW のどれでビルドしても同じ。実機は Galaxy S9 と iPhone 11。3 つのエンジンが同じビルド済みのコアを呼ぶ
通信量片方向 32〜48 B / tickリアルタイムの入力・返事・照合。UDP / IP の見出しを除く
ロールバック 2D3.50 ms / フレームベイクした凹形状 200 体・10 tick 計算し直す・i7-12700F・ワーカー 4
ロールバック 3D3.15 ms / フレーム箱・球・カプセル・凸包 200 体・N = 10・i7-12700F・ワーカー 4
モバイル60 体・N = 10 で 4 ms 以内ベイクした凹形状・Galaxy S9（Snapdragon 845）
desync の報告約 0.3 秒見つけてから両方の端末に同じ報告がそろうまで・PC と Galaxy S9
