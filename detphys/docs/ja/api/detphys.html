detphys.hワールド・step・ハッシュ・ワーカー・snapshot（バージョン 2）

関数説明
detphys_abi_versionこのヘッダーのバージョン（DETPHYS_ABI_VERSION）。起動時に >= で比べる
detphys_build_infoビルドの情報（コンパイラ・CPU・浮動小数点の設定・SIMD）の 1 行。比較のログ用
detphys_world_desc_defaultワールドの設定の既定値（60 Hz・4 サブステップ・重力 (0, −10000) mm/s²）
detphys_world_createワールドを作る（NULL なら既定値）。detphys_world_create_ex(desc, NULL) と同じ
detphys_world_destroyワールドを壊す
detphys_world_step1 tick 進める
detphys_world_tick今の tick 番号（作った直後は 0）
detphys_world_hash状態のハッシュ（FNV-1a 64。tick・ボディの数・各ボディの位置・回転・速度・角速度の生のビット）使い方: コンセプト › tick
detphys_world_options_defaultワーカーなどの設定の既定値（ワーカー 1・コアのプール・spin 4000・base 4 個）
detphys_world_create_ex設定とワーカーの設定を渡してワールドを作る
detphys_world_get_options作った時のワーカーの設定を読む
detphys_world_snapshot_size今の状態の snapshot の大きさを数える（dyn / full）
detphys_world_snapshot_writesnapshot を呼び出し側のバッファに書く（dyn で base が無ければここで取る）
detphys_world_snapshot_restoresnapshot の状態に戻す（tick・ボディの一覧も戻る。full を戻すと形のバージョンは必ず新しくなり、次の dyn で base を取り直す）
detphys_snapshot_read_infosnapshot の画像の見出しを読む（ワールドは要らない）
detphys_world_get_snapshot_statsbase の数・形のバージョン・書いた回数などの様子
構造体説明
detphys_worldワールド（中身は見えない）使い方: クイックスタート › ワールドとハッシュ（1 台）
detphys_world_desctick の速さ・サブステップ・重力（mm/s²）
detphys_world_optionsワーカー数（1〜64）・プール（DETPHYS_POOL_OWN / BOX2D / EXTERNAL）・spin・base の数・エンジンのジョブの関数
detphys_snapshot_info画像の見出し（種類・大きさ・ボディの数・tick・base の番号）
detphys_snapshot_statssnapshot の様子（調整用）

型: detphys_task_fn・detphys_enqueue_task_fn・detphys_finish_task_fn（エンジンのジョブの仕組みを渡す時の関数の形）。定数: DETPHYS_SNAPSHOT_DYNAMIC / DETPHYS_SNAPSHOT_FULL、DETPHYS_MAX_WORKERS（64）。
