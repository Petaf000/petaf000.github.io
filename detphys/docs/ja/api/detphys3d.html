detphys3d.h3D のワールド・ボディ・凸包・snapshot・送る状態（バージョン 2）

物理の土台は Box3D です。2D（detphys.h・detphys_body.h）と同じ流儀で、エラー（DETPHYS_ERR_*）・ワーカーのジョブの型・snapshot の種類と detphys_snapshot_info / detphys_snapshot_stats は 2D のものを使います。長さは mm・速さ mm/s・角速度 mrad/s・力 mN・トルク mN·m・材質 ×1000 の整数です。向きは整数の四元数（qx, qy, qz, qw。大きさは自由で、コアが正規化します。float の四元数は DETPHYS3D_QUAT_ONE〔2^30〕倍して丸めて渡します。0, 0, 0, 0 は回転なし）なので、三角関数を使いません。

構造体説明
detphys3d_world3D のワールド（中身は見えない）
detphys3d_world_desctick の速さ・サブステップ・重力 xyz・ワーカー 1〜32・プール（DETPHYS3D_POOL_OWN / BOX3D / EXTERNAL）・flags（NO_SLEEP・NO_CONTINUOUS・SSE2）・接触の調整（0 = Box3D の既定）。88 B使い方: コンセプト › 3D
detphys3d_shape_desc1 つの形（DETPHYS3D_SHAPE_BOX / SPHERE / CAPSULE / HULL・大きさ・中心・向き・材質）。88 B
detphys3d_body_descボディの設定（種類 DETPHYS3D_BODY_STATIC / KINEMATIC / DYNAMIC・位置・整数の四元数・速度・角速度・減衰・重力の倍率・flags〔BULLET・NO_SLEEP・軸ごとの LOCK_*〕・tag・最初の形）。176 B
detphys3d_body_view読み出した状態（ID・種類・flags・tag・形・整数の位置 x_mm/y_mm/z_mm・描画用の float）。96 B使い方: 決定論を守るためのルール › 2. float をシミュレーションに入れない
detphys3d_hull_info登録した凸包の情報
detphys3d_world_statsワールドの様子
detphys3d_transfer_infotransfer の見出し（大きさ・凸包・登録簿・画像のバイト数・tick。戻した時は flags〔DETPHYS3D_TRANSFER_REBUILT_REGISTRY・REPLACED_HULLS〕）
  • full の snapshot は「同じ形を同じ順で作った」別のワールドにも戻せますが、形の登録簿の並びが違うと DETPHYS_ERR_FORMAT（ワールドは変わらない）です。別のピアに送るなら transfer を使います（セッションは自動でそうします）。
  • detphys_world_snapshot_restore・detphys3d_world_snapshot_restore で full を戻すと、自分のワールドで取った画像でも、形のバージョン（detphys_snapshot_stats の shape_version）は必ず新しくなります（別のプロセスのワールドの画像と見分けられないため）。結果・ハッシュは変わりません。自前のロールバックの輪で full と dyn を混ぜていると、full を戻した後の最初の dyn で base を取り直すので、その 1 回だけ full を書くのと同じくらいかかります。コアのセッション（rt・ターン制）の輪は自分の画像だけなので、この取り直しはありません。
  • 画像・transfer は x64 と arm64 で同じバイト列です（iOS・32 bit はまだ確かめていません）。
  • まだ無いもの: ジョイント・センサー・接触のイベント・レイの問い合わせ。
  • desync デバッガーは 3D のワールドも記録できます（上の detphys_debug.h の detphys_debug_record3d）。
  • 3D の動く凹形状は次の detphys3d_kinematic.h です。
