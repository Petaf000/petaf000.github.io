detphys_link.hトランスポートのインターフェース・ルームコード（バージョン 1）

相手を見つけてつなぐ層（8. トランスポートとルームコード）。中から detphys_transport を取り出してセッションに渡す。

関数説明
detphys_link_abi_versionこのヘッダーのバージョン（DETPHYS_LINK_ABI_VERSION）
detphys_link_create実装の表（detphys_link_vtable）から API を作る（自分のトランスポートを載せる時）使い方: トランスポートとルームコード › 自分のトランスポートを書く（自社のサーバーなど）
detphys_link_destroy壊す（ルームを出る）
detphys_link_transportセッションに渡すトランスポートのインターフェースを取る（送った・受け取った数は API が数える）使い方: トランスポートとルームコード › 使い方（どのトランスポートでも同じ）
detphys_link_poll毎フレーム呼ぶ。今の状態を返す使い方: トランスポートとルームコード › ゲームの側
detphys_link_room_desc_defaultルームの決め方の既定値
detphys_link_hostルームを作る（ホストになる）。ルームコードは作られるか、決めたものを使う使い方: トランスポートとルームコード › 使い方（どのトランスポートでも同じ）
detphys_link_joinルームコードでルームに入る（ゲストになる）。打ち間違いは通信の前に返す使い方: トランスポートとルームコード › 使い方（どのトランスポートでも同じ）
detphys_link_closeルームを出る
detphys_link_wait受け取れる物が来るまで待つ（ヘッドレスのテスト用）
detphys_link_get_info状態・役・経路・理由・数え上げ・ルームコード
detphys_link_error最後の失敗の説明（NULL を渡すと、作るのに失敗した理由）使い方: トランスポートとルームコード › 状態と理由
detphys_link_state_name / detphys_link_reason_name状態・理由の英数字の名前（翻訳の鍵用）使い方: トランスポートとルームコード › 状態と理由
detphys_room_code_make種からルームコード（6 桁）を作る
detphys_room_code_parse打った文字を確かめて 6 桁に正規化する（全角・区切りを読み飛ばす。形の誤り / チェックディジットの誤り）使い方: トランスポートとルームコード › ルームコード
detphys_link_create_udpUDP（detphys_udp.h）の API。役は作る時に決める使い方: トランスポートとルームコード › DetPhys に入っているトランスポート
detphys_link_create_loopbackループバックの side を包んだ API使い方: トランスポートとルームコード › DetPhys に入っているトランスポート
detphys_link_hub_desc_defaultテスト用のロビーの設定の既定値
detphys_link_hub_create / detphys_link_hub_destroyテスト用のロビーを作る・壊す使い方: トランスポートとルームコード › DetPhys に入っているトランスポート
detphys_link_hub_pumpテスト用のロビーの時間を 1 進める使い方: トランスポートとルームコード › DetPhys に入っているトランスポート
detphys_link_hub_room_count今のルームの数
detphys_link_create_hubテスト用のロビーにつながる API を作る使い方: トランスポートとルームコード › DetPhys に入っているトランスポート
構造体説明
detphys_linkトランスポートのインターフェース（中身は見えない）使い方: トランスポートとルームコード › 使い方（どのトランスポートでも同じ）
detphys_link_room_descルームの決め方（人数・bucket・ルームコード・コードを作る種・時間切れ）使い方: トランスポートとルームコード › ルームコード
detphys_link_info状態・役・経路・理由・往復時間・データグラムの上限・いちばん大きく送ったもの・数え上げ・種類・ルームコード・相手と自分の説明使い方: トランスポートとルームコード › ルームコード
detphys_link_vtable実装の表（send・recv・get_info は要る。poll・host・join・wait・error・close・destroy は任意）使い方: トランスポートとルームコード › 自分のトランスポートを書く（自社のサーバーなど）
detphys_link_hubテスト用のロビー（中身は見えない）
detphys_link_hub_descテスト用のロビーの設定（操作にかかる時間・ルームの数の上限・見せる経路・データグラムの上限・ルームごとのトランスポート）使い方: トランスポートとルームコード › DetPhys に入っているトランスポート

定数: 戻り値 DETPHYS_LINK_OK・DETPHYS_LINK_E_*（ARGUMENT・UNSUPPORTED・STATE・CODE_FORMAT・CODE_CHECK・TOO_LARGE・NOT_READY・BACKEND・MEMORY）、状態 DETPHYS_LINK_STATE_*（IDLE・OPENING・WAITING・CONNECTED・CLOSED・FAILED）、役 DETPHYS_LINK_ROLE_*（HOST = 0・GUEST = 1・UNKNOWN）、経路 DETPHYS_LINK_PATH_*（UNKNOWN・DIRECT・RELAYED・LOCAL）、理由 DETPHYS_LINK_REASON_*、ルームコード DETPHYS_ROOM_CODE_DIGITS（6）・DETPHYS_ROOM_CODE_SIZE（8）。
