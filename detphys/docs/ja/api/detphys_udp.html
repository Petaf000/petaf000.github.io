detphys_udp.hLAN 用の UDP のトランスポート

関数説明
detphys_udp_desc_default設定の既定値
detphys_udp_createソケットを作る（DETPHYS_UDP_LISTEN で待ち受け / DETPHYS_UDP_CONNECT でつなぐ。IPv4）
detphys_udp_destroy壊す
detphys_udp_transportセッションに渡すトランスポートのインターフェースを取る
detphys_udp_wait受け取れるものが来るまで待つ（ヘッドレスのテスト用。エンジンでは毎フレーム poll する）
detphys_udp_get_stats送った・受け取った数など
detphys_udp_peer今の相手のアドレス（"a.b.c.d:port"）
detphys_udp_last_error最後に失敗した時の説明
構造体説明
detphys_udpソケット（中身は見えない）使い方: コンセプト › トランスポート
detphys_udp_desc形（LISTEN / CONNECT）・アドレス・ポート・バッファの大きさ
detphys_udp_statsUDP の数え上げ
