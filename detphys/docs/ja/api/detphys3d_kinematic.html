detphys3d_kinematic.h3D の動く凹形状（バージョン 1）

2D の detphys_kinematic.h と同じ考え方を、3D のワールド（detphys3d.h）に足したヘッダーです。足しただけで、ほかのヘッダーの関数とバージョンは変えていません（3D のセッションに表を渡す API も、このヘッダーにあります）。表の設定（detphys_kinematic_desc）・様子（detphys_kinematic_stats）・区間の速さ（DETPHYS_EASE_*）・動きの flags（DETPHYS_MOTION_*）・セッションの flags（DETPHYS_KINEMATIC_SESSION_*）は 2D のものをそのまま使います。単位は mm・mrad・mrad/s・tick の整数、向きは整数の四元数です。考え方と使い方は 3. コンセプト にあります。

関数説明
detphys3d_kinematic_abi_versionこのヘッダーのバージョン（DETPHYS3D_KINEMATIC_ABI_VERSION）
detphys3d_motion_desc_default動きの設定の既定値（FIXED・SMOOTH・回転軸 y）
detphys3d_kinematic_createキネマティックの表を作る（NULL なら既定値: 分割 最大 4 回・20 mm）。ワールドごとに 1 つ。ワールドより先に壊しても後に壊してもよい
detphys3d_kinematic_destroy壊す
detphys3d_kinematic_add動きを付けたキネマティックのボディを作り、ID を返す。形は body->shape（detphys3d_world_add_shape で足して凸の組にできる）使い方: コンセプト › 動く凹形状（3D）
detphys3d_kinematic_bind今あるキネマティックのボディに動きを付ける（付いていれば置き換える。すぐに今の tick の姿勢に合わせ、角速度の上限を外す）
detphys3d_kinematic_unbind動きを外す（ボディは残り、最後の速度で動き続ける。止めるなら detphys3d_world_set_velocity で 0 に）
detphys3d_kinematic_clear動きを全部外す（ボディはワールドに残る。セッションが begin の前に呼ぶ）
detphys3d_kinematic_update今の tick の姿勢に合わせ、次の tick の姿勢に着く速度・角速度を与える（detphys3d_world_step の後に毎回。何度呼んでも同じ）
detphys3d_kinematic_step1 tick 進める（detphys3d_world_step の代わり。速い tick は最大 max_subticks 回に分け、最後に update）。戻り値は分けた回数
detphys3d_kinematic_pose_at動きの関数の値（tick の中の位置 sub_milli 0〜999 も。描画の補間用）。向きは DETPHYS3D_QUAT_ONE 倍して丸めた整数の四元数（続けて回した向きなので qw ≥ 0 とは限らない）
detphys3d_kinematic_checkワールドの中の位置・向き・速度・角速度の生のビットが、関数から作り直した値と同じか（戻り値は違ったボディの数。0 = 全部同じ）使い方: desync への対処 › 動く凹形状がある時
detphys3d_kinematic_get_stats分割の回数などの様子（2D と同じ detphys_kinematic_stats）
detphys3d_kinematic_session_defaultセッションに渡す設定の既定値
detphys_rt_create3d_kinematicdetphys_rt_create3d と同じだが、3D の表も渡して作る使い方: コンセプト › 動く凹形状（3D）
detphys_turn_create_rule3d_kinematicdetphys_turn_create_rule3d と同じだが、3D の表も渡して作る（試合ごとに begin_match の前に表を空にする）使い方: コンセプト › 動く凹形状（3D）
detphys_rt_kinematic3dリアルタイムのセッションが動かしている 3D の表（読むだけ。無ければ NULL）
detphys_turn_kinematic3dターン制のセッションが動かしている 3D の表（読むだけ。無ければ NULL）
構造体説明
detphys3d_kinematic3D のキネマティックの表（中身は見えない）使い方: コンセプト › 動く凹形状
detphys3d_motion_desc動き（経路 DETPHYS3D_PATH_*・ease・flags・位置 A / B・初めの向き〔整数の四元数〕・回転軸・spin・orbit・片道の tick 数・両端で止まる tick 数 hold_a_ticks / hold_b_ticks・phase・点・コールバック）。128 B使い方: コンセプト › 動く凹形状（3D）
detphys3d_motion_pointPOINTS の点（位置 mm・回転軸のまわりの角度 mrad・次の点までの tick 数）。24 B
detphys3d_kinematic_poseコールバックが返す姿勢（位置 [µm]・整数の四元数）。40 B
detphys3d_kinematic_sessionセッションに表を渡す設定（表・flags NO_PRE_UPDATE / NO_SPLIT）

型: detphys3d_motion_fn（CALLBACK の動きの関数の形。user・ボディの ID・tick を受け取り、姿勢を書いて 0 を返す。負 = 失敗）。

定数: DETPHYS3D_KINEMATIC_ABI_VERSION（1）・経路 DETPHYS3D_PATH_FIXED（0）・DETPHYS3D_PATH_PINGPONG（1）・DETPHYS3D_PATH_ORBIT（2）・DETPHYS3D_PATH_POINTS（3）・DETPHYS3D_PATH_CALLBACK（4）。

  • 1 tick の流れ（全ピアで同じ。ロールバックの再計算でも同じ）: update（tick の初め。NO_PRE_UPDATE なら省く）→ ルールの apply_inputs（ターン制は apply_input）→ detphys3d_kinematic_step（NO_SPLIT なら detphys3d_world_step → update）→ after_tick。
  • 表はセッションより長く生かし、ピアごと・セッションごとに 1 つ作ります（セッションは写し取りません。ほかのワールドと共有しません）。
  • 表の分割の設定・flags・付けた動き（begin の後の中身）は設定の照合に入るので、違う動きのピアとはつながりません。表を渡さないセッションの照合の値は前と同じです。
  • 表を変える（add / bind / unbind / clear）のは begin（begin_match）の中だけです。表はロールバックで戻らないので、途中で動きを変えたいなら、動きそのものを tick の関数にします（POINTS で止まる区間を作る・CALLBACK で tick から決める）。
  • ロールバック（snapshot の restore）の後は何もしなくてかまいません（snapshot に関数の値が入っています）。表は snapshot にも snapshot のリングにも入りません。
  • 構造体は固定幅の整数とポインタだけで、64 bit で暗黙の詰め物はありません。
