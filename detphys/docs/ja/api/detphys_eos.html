detphys_eos.hEOS P2P のトランスポート（バージョン 2）

Epic Online Services の P2P を通すトランスポートのインターフェース。別のライブラリ detphys_eos（Windows・Android。Epic から入手する EOS SDK を読み込みます）に入っています。使い方と Android・iOS の準備は 8. トランスポートとルームコード の「EOS P2P」。

関数説明
detphys_eos_abi_versionこのヘッダーのバージョン（DETPHYS_EOS_ABI_VERSION）
detphys_eos_sdk_version読み込んだ EOS SDK のバージョンの文字列（SDK の置き場所とリンクを確かめる時に）
detphys_eos_desc_default設定の既定値使い方: トランスポートとルームコード › EOS P2P
detphys_eos_link_createEOS のトランスポート（detphys_link）を作る。最初の 1 つで EOS を初期化し、デバイス ID でのログインを始める（ログインは detphys_link_poll の中で進むので、待たずに detphys_link_host / detphys_link_join を呼べる）。同時に使えるのは 1 プロセスに 1 つ使い方: トランスポートとルームコード › DetPhys に入っているトランスポート
detphys_eos_last_error最後に detphys_eos_link_create が失敗した理由（無ければ ""）使い方: トランスポートとルームコード › EOS P2P
detphys_eos_shutdownEOS を片付ける。プロセスの終わりに 1 回だけ呼ぶ（トランスポートが残っている時は何もせず DETPHYS_LINK_E_STATE。呼んだ後は、同じプロセスで EOS のトランスポートをもう作れない）使い方: トランスポートとルームコード › EOS P2P
構造体説明
detphys_eos_desc開発者ポータルの値（製品 ID・サンドボックス ID・デプロイメント ID・クライアント ID とクライアントのシークレット）・製品の名前とバージョン・ログインに使う名前・キャッシュの置き場所・ソケットの名前・ログインの時間切れ・ログの詳しさ・リレーの使い方・flags使い方: トランスポートとルームコード › EOS P2P

定数: 1 つのデータグラムの上限 DETPHYS_EOS_MAX_PACKET（1170）、リレーの使い方 DETPHYS_EOS_RELAY_*（ALLOW = 既定・FORCE・NEVER）、flags DETPHYS_EOS_FLAG_NEW_DEVICE_ID（1 台で 2 人を試す時の 2 つ目のプロセス用。ゲームでは使わない）。
