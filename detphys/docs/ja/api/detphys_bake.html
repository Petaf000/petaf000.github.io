detphys_bake.h凹形状のベイカー（バージョン 1）

画像（のアルファ）から、凸多角形（1 つ 8 頂点まで）の組でできた凹形状を作り、.dnshape のバイト列（整数の頂点・原点は画像の中心・y が上）にします。できたバイト列は、ワールドやセッションに mesh として登録します。エディタで使う道具で、シミュレーションの中では何も動きません。判断はすべて整数で行うので、同じ画像と設定なら、どのプラットフォームでも同じバイトになります。各エディタのベイカー（3. コンセプト）もこの関数を呼んでいます。

関数説明
detphys_bake_abi_versionこのヘッダーのバージョン（DETPHYS_BAKE_ABI_VERSION）
detphys_bake_params_default既定の設定（1 m = 1000 単位 = mm、1 m = 128 px、アルファ 128 以上が内側、1 つ 8 頂点まで、Steiner、許容誤差 1 px）
detphys_bake_alpha・detphys_bake_rgba・detphys_bake_pngアルファの画像（1 画素 1 バイト）・RGBA の画像（4 バイト目がアルファ）・PNG ファイルのバイト列をベイクする（行は上から。16384 x 16384 px まで）。params は NULL でもよい（既定値）。結果は必ず返る（NULL はメモリが足りない時だけ）
detphys_bake_statusDETPHYS_OK・DETPHYS_BAKE_ERR_IMAGE（−20、画像を読めない）・DETPHYS_BAKE_ERR_SHAPE（−21、形を作れない）・DETPHYS_ERR_ARGUMENT / DETPHYS_ERR_INTERNAL
detphys_bake_error失敗した理由（英語の 1 文。成功の時は空）
detphys_bake_data.dnshape のバイト列（失敗の時は NULL）。結果を消すまで使える
detphys_bake_get_statsベイクの数字（detphys_bake_stats）
detphys_bake_read_outline間引いた輪郭（プレビュー用。輪の数と頂点、頂点の単位）
detphys_bake_png_alphaPNG のアルファだけを読む（alpha = NULL で呼ぶと先に大きさが分かる）
detphys_bake_result_destroy結果を消す
構造体説明
detphys_bake_params1 m の単位数・1 m の画素数・アルファのしきい値・1 つの凸多角形の頂点の上限（3〜8）・分け方（DETPHYS_BAKE_STEINER = 既定、DETPHYS_BAKE_HM = Hertel-Mehlhorn）・間引きの許容誤差（px）・頂点の出っ張りの下限（mm）・小さな島の下限（px）・Steiner の点を端に寄せる距離（mm）
detphys_bake_stats画像の大きさ・凸多角形の数と頂点・輪郭の輪と頂点・埋めた穴・捨てた小さな島・消した頂点・足した Steiner の点・範囲・使った許容誤差・元の輪郭からのいちばん大きな距離（mm）
detphys_bake_resultベイクの結果（中身は見えない）
