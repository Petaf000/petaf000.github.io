#組み込みのルール: 押し合い（バージョン 5）

2 人のプレイヤー（円）が入力 2 語 [移動 −100〜100, ボタン（1 = ジャンプ・2 = ダッシュ）] で、箱と凹形状を押し合うリアルタイムのルールです。コールバックはコアの中（C++）にあるので、エンジンからはセッションを作るだけです。Unity の DetPhysRtSession.CreatePush・Godot の DetPhysRtSession.create_push もこれを呼びます。同じ設定なら、どのエンジン・どの端末でも同じ確定 tick のハッシュになり、つながります。動くステージ（field）を選ぶと、回る歯車（DETPHYS_RULE_PUSH_FIELD_GEAR）・往復する足場（PLATFORM）・上下する U（LIFT）が凹形状で足され、そのキネマティックの表はセッションが作って持ちます。

関数説明
detphys_rule_push_desc_default押し合いの設定の既定値（箱 60・凹形状 12・形 8・床の幅の半分 12000 mm・動くステージなし・予測 REPEAT）
detphys_rt_create_push押し合いのセッションを作る（いちばん簡単な API。動くステージがあれば表も作り、detphys_rt_destroy で一緒に壊す）。失敗は NULL使い方: トランスポートとルームコード › 使い方（どのトランスポートでも同じ）
detphys_rt_rule_push押し合いのルールだけを書く（ルールを包みたい・自分の表を使いたい時。動くステージなら rule.user に表を入れて detphys_rt_create_kinematic）
detphys_rule_push_get_layoutbegin が作るボディの番号（床 0・壁 1・2・プレイヤー 3・4・箱・形・動くステージ）。セッションを作らずに分かる使い方: コンセプト › ルール
detphys_rt_kinematicセッションが動かしているキネマティックの表（読むだけ。無ければ NULL）
構造体説明
detphys_rule_push_desc押し合いの設定（144 B: 箱・凹形状の数、seed、床・壁・プレイヤーの大きさ、力・速さ・ジャンプ・ダッシュ、動くステージ field〔GEAR 1・PLATFORM 2・LIFT 4・ALL 7〕・速さ %・落とす高さ・形の番号、predict〔REPEAT / RELEASED〕、表の分割の設定 kinematic_*）
detphys_rule_push_layoutボディの番号の並びと params の大きさ（88 か 120 バイト）

定数: DETPHYS_RULE_PUSH_ID・DETPHYS_RULE_PUSH_INPUT_WORDS（2）・DETPHYS_RULE_PUSH_STATE_WORDS（4）・DETPHYS_RULE_PUSH_TAG_*（箱 1・形 2・動くステージ 3・プレイヤー 100 + ピア）。

#3D のセッション（バージョン 6）

1 tick の流れ・予測・ロールバック・照合・再同期・再接続・入力遅延の自動調整は 2D と同じで、ワールドが 3D（detphys3d.h）になります。違う所:

  • ワールドの設定は detphys3d_world_desc です。設定の world・meshes・worker_count・snapshot_base_slots は使わず（mesh_count は 0）、凸包は begin の中で両方のピアで同じ順に登録します（凸包の中身は設定の照合に入ります）。
  • snapshot のリングの snapshot は full を勧めます（detphys_rt_config_default3d が FULL にします）。照合のハッシュは detphys3d_world_hash ＋状態ワードです。
  • 再同期・再接続で送る状態は detphys3d_world_transfer_*（形の登録簿と凸包の表も入る）なので、受け取った側の登録簿が予測でずれていても戻せます。
  • desync デバッガー（detphys_rt_set_debug）は 3D でも使えます（detphys_debug_abi_version() が 3 以上。記録は 3D の形式で、報告のフィールドは 3D のフィールド。5. desync への対処）。
  • 3D のキネマティックの表（キネマティック）は detphys3d_kinematic.h の detphys_rt_create3d_kinematic で渡します（この下の detphys3d_kinematic.h の節）。
関数説明
detphys_rt_config_default3dセッションの設定（snapshot は FULL）と 3D のワールドの設定を既定値にする（どちらも NULL でよい）
detphys_rt_create3d3D のセッションを作る（ワールドの設定が NULL なら既定値）。あとは 2D と同じく poll → advance → next_confirmed使い方: コンセプト › 3D
detphys_rt_world3d今の 3D のワールド（予測を含む。描画用に読む）。3D のセッションでは detphys_rt_world は NULL使い方: コンセプト › 3D
detphys_rt_get_resync_info再同期・再接続で送った・受け取った状態の様子（回数・登録簿を作り直した回数・大きさ・戻した時間）。2D でも使える
構造体説明
detphys_rt_rule3d3D のルール（detphys_rt_rule と同じ並びで、コールバックが detphys_rt_ctx3d を受け取る。72 B）
detphys_rt_ctx3dコールバックに渡す値（detphys_rt_ctx と同じ並びで、world だけが detphys3d_world*）
detphys_rt_resync_info再同期の様子（dimensions 2 / 3・送った・受け取った・registry_rebuilds・hull_replacements・最後の大きさ・tick・時間）

#組み込みのルール: 3D の押し合い（バージョン 8）

2 人のプレイヤー（球）が入力 3 語 [移動 x, 移動 z（−100〜100）, ボタン（1 = ジャンプ・2 = ダッシュ・4 = 箱を出す）] で、床と 4 枚の壁の中の箱・球・凸包（seed から作る 6 種）を押し合う、3D のリアルタイムのルールです。2D の押し合いと同じく、コールバックはコアの中（C++）にあるので、エンジンからはセッションを作るだけです。params と rule id は Unity のサンプル「3D の押し合い」の C# のルールと同じなので、同じ設定なら確定 tick のハッシュも同じで、そのピアともつながります。回る台（field = DETPHYS_RULE_PUSH3D_FIELD_TURNTABLE）を選ぶと、16 角の円盤に低い壁 3 枚を載せた凹形状の台が tick の関数で回り、その 3D のキネマティックの表はセッションが作って持ちます（detphys_rt_kinematic3d で読めます）。

関数説明
detphys_rule_push3d_desc_default3D の押し合いの設定の既定値（箱 40・球 8・凸包 12・1 人 24 個まで箱を出せる・seed 0x5EED0036・回る台なし〔速さ 800 mrad/s・中心 (0, +7 m)〕・予測 REPEAT）
detphys_rt_create_push3d3D の押し合いのセッションを作る（いちばん簡単な API。ワールドの設定が NULL なら既定値。回る台があれば表も作り、detphys_rt_destroy で一緒に壊す）。失敗は NULL使い方: クイックスタート › 3D の押し合い（Box3D・リアルタイム、入力遅延 0）
detphys_rt_rule_push3d3D の押し合いのルールだけを書く（detphys_rt_rule3d。ルールを包みたい・自分の表を使いたい時。回る台なら rule.user に detphys3d_kinematic* を入れて detphys_rt_create3d_kinematic）
detphys_rule_push3d_get_layoutbegin が作るボディ・凸包の番号（床 0・壁 1〜4・プレイヤー 5・6・箱・球・凸包・回る台、その後に試合中に出した箱）。セッションを作らずに分かる
detphys_rule_push3d_auto_inputsサンプルの自動の入力（tick 0〜ticks、1 tick 3 語）。基準のハッシュと比べる時に使う
構造体説明
detphys_rule_push3d_desc3D の押し合いの設定（144 B: 箱・球・凸包の数、出せる箱の数、seed、床・壁・プレイヤーの大きさ、力・速さ・ジャンプ・ダッシュ・箱を出す間隔、物の大きさ・密度・摩擦、回る台 field〔NONE 0・TURNTABLE 1〕・速さ・中心、predict〔DETPHYS_RULE_PUSH_PREDICT_*〕、表の分割の設定 kinematic_*）
detphys_rule_push3d_layoutボディの番号の並び（回る台 table_body・試合中に出した箱 first_dropped）・凸包の番号（石 hull_types・台の円盤 table_hull）と params の大きさ（88 か 104 バイト）

定数: DETPHYS_RULE_PUSH3D_ID・DETPHYS_RULE_PUSH3D_INPUT_WORDS（3）・DETPHYS_RULE_PUSH3D_STATE_WORDS（8）・DETPHYS_RULE_PUSH3D_BUTTON_*・DETPHYS_RULE_PUSH3D_TAG_*（箱 1・球 2・凸包 3・回る台 7・出した箱 50 + ピア・プレイヤー 100 + ピア）・DETPHYS_RULE_PUSH3D_FIELD_*。
