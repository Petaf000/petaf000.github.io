detphys_debug.hdesync デバッガー（バージョン 3・記録の形式 DNDR 2・バンドル DNDB 1）

バージョン 3 で 3D のワールド（detphys3d.h）の記録を足しました（足しただけ）。

  • 記録の設定 detphys_debug_config の reserved を dimensions に改名しました（0 か 2 = 2D、3 = 3D。0 のままなら今までと同じ）。
  • 3D の記録は形式のバージョン 2 で書きます。2D の記録は今も形式 1 で、バイト列はバージョン 2 の時と同じです。2D と 3D の記録を比べると DETPHYS_ERR_FORMAT です。
  • 3D のセッション（detphys_rt_create3d・detphys_turn_create_rule3d）でも detphys_rt_set_debug / detphys_turn_set_debug を ON にできます（rt・ターン制のバージョンは変わらないので、detphys_debug_abi_version() >= 3 で見分けます）。
  • 3D では、box2d_hash・box2d_first_tick・DETPHYS_DEBUG_REC_BOX2D_HASH の中身は Box3D の状態のハッシュ（detphys3d_world_engine_hash と同じ値）です。名前は 2D と同じです。
