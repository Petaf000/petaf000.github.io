API リファレンス（C ABI）

コアの C ABI は、下の C のヘッダーです（2D は detphys_*、3D は detphys3d_*）。エンジンの層もこの関数を呼んでいます。

共通の規約

  • 構造体は固定幅の整数・float・関数ポインタだけで、暗黙の詰め物はありません（C# の StructLayout.Sequential でそのまま読めます）。
  • struct_size のある構造体は、sizeof を入れて渡します。設定は *_default で既定値を入れてから変えます。
  • 失敗は戻り値で返します（DETPHYS_OK = 0、負 = DETPHYS_ERR_*）。可変長のもの（snapshot・記録・バンドル）は呼び出し側のバッファに書き、足りなければ DETPHYS_ERR_CAPACITY と要るバイト数を返します。
  • 入る値は全部整数です（長さ mm・角度 mrad・速さ mm/s・力 mN・力積 mN·s・材質 ×1000。3D の向きは整数の四元数）。
戻り値意味
DETPHYS_OK (0)成功
DETPHYS_ERR_ARGUMENT (−1)NULL・範囲の外・struct_size が違う
DETPHYS_ERR_CAPACITY (−2)呼び出し側のバッファが足りない（*out_size に要るバイト数）
DETPHYS_ERR_FORMAT (−3)snapshot・記録の形式が違う・壊れている（ワールドは変わらない）
DETPHYS_ERR_BASE (−4)dyn の snapshot の base が無い（ワールドは変わらない）
DETPHYS_ERR_CORRUPT (−5)戻している途中で失敗した（ワールドを壊して作り直す）
DETPHYS_ERR_INTERNAL (−6)確保できない・スレッドを作れない
