detphys_kinematic.h動く凹形状（バージョン 2）

関数説明
detphys_kinematic_abi_versionこのヘッダーのバージョン
detphys_kinematic_desc_default表の設定の既定値（分割 最大 4 回・20 mm）
detphys_motion_desc_default動きの設定の既定値（FIXED・SMOOTH）
detphys_kinematic_createキネマティックの表を作る（ワールドごとに 1 つ）
detphys_kinematic_destroy壊す
detphys_kinematic_addキネマティックのボディを作って動きを付ける（角速度の上限を外してある）
detphys_kinematic_bind今あるボディに動きを付ける
detphys_kinematic_unbind動きを外す
detphys_kinematic_clear動きを全部外す（セッションが begin の前に呼ぶ）
detphys_kinematic_update今の tick の位置に合わせ、次の tick に着く速度を与える
detphys_kinematic_step1 tick 進める（detphys_world_step の代わり。速い tick は分割し、最後に update）
detphys_kinematic_pose_at動きの関数の値（tick の間の位置も。描画の補間用）
detphys_kinematic_checkワールドの値が関数から作り直した値とビットまで同じか使い方: desync への対処 › 動く凹形状がある時
detphys_kinematic_get_stats分割の回数などの様子
detphys_kinematic_session_defaultセッションに渡す設定の既定値
構造体説明
detphys_kinematicキネマティックの表（中身は見えない）使い方: コンセプト › 動く凹形状
detphys_kinematic_desc分割の設定（max_subticks 1〜16・subtick_move_mm）
detphys_motion_desc動き（経路 DETPHYS_PATH_*・ease・位置・spin・orbit・周期・phase・点・コールバック）使い方: コンセプト › 動く凹形状
detphys_motion_pointPOINTS の点（位置・角度・次の点までの tick 数）
detphys_kinematic_poseコールバックが返す位置 [µm]・角度 [µrad]
detphys_kinematic_stats表の様子
detphys_kinematic_sessionセッションに表を渡す設定（flags NO_PRE_UPDATE / NO_SPLIT）

型: detphys_motion_fn（CALLBACK の動きの関数の形）。
