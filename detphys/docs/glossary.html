用語の対訳 / Glossary (ja ⇔ en)

日本語バージョン（ja/）が元で、英語バージョン（en/）はその訳です。訳すときは、この表の言葉にそろえてください。 The Japanese manual (ja/) is the source; the English manual (en/) is its translation. Use the terms below in both.

日本語English意味 / Meaning
決定論determinism, deterministic同じ設定と同じ入力なら、どの端末でもビットまで同じ結果になること / same settings and inputs give bit-identical results on every device
ticktickシミュレーションの 1 歩（既定 60 Hz） / one simulation step (60 Hz by default)
サブステップsubstep1 tick の中で物理を細かく進める回数（既定 4） / physics sub-iterations inside one tick (default 4)
ワールドworldボディと形をまとめた物理の世界 / the physics world holding bodies and shapes
ボディbody動く・動かない物体（静的・キネマティック・動く） / a rigid body (static, kinematic, dynamic)
形shapeボディに付ける当たりの形（箱・円・メッシュ） / a collision shape attached to a body (box, circle, mesh)
凸多角形convex polygon8 頂点までの凸の多角形。凹形状はこれの組で表す / a convex polygon of up to 8 vertices; concave shapes are sets of these
凹形状concave shapeへこみのある形（歯車・U 字・くし） / a shape with dents (gear, U, comb)
ベイカーbaker画像から凸多角形の組を作るオフラインの道具 / the offline tool that turns an image into a set of convex polygons
分解decomposition凹形状を凸多角形に分けること（steiner / hm） / splitting a concave shape into convex polygons
量子化quantize, quantization小数を整数（mm・mrad など）にすること / turning a decimal value into an integer (mm, mrad, …)
入力input1 tick（ターン制は 1 ターン）にプレイヤーが出す整数の列 / the integers a player sends per tick (per turn in turn-based)
ゲームの状態（状態ワード）game state (state words)ルールが持つ int32 の列。ロールバックで戻り、ハッシュに入る / the rule's int32 words; rolled back and hashed
ルールrule入力をワールドに入れるゲームのコード（コールバック） / the game code (callbacks) that applies inputs to the world
組み込みのルールbuilt-in ruleコアに入っているルール（積み上げ・押し合い） / a rule shipped with DetPhys (stacking, push)
押し合いpush組み込みのリアルタイムのルール。2 人が箱と凹形状を押し合う / the built-in real-time rule where two players push boxes and concave shapes
動くステージmoving field押し合いに足せる回る歯車・往復する足場・上下する U / the spinning gear, sliding platform and lift that the push rule can add
凸包convex hull3D の凸の形。点から作ってワールドに登録し、番号で付ける / a 3D convex shape built from points, registered in the world and attached by index
整数の四元数integer quaternion3D の向き（qx, qy, qz, qw の整数。コアが正規化する） / a 3D orientation as integers (qx, qy, qz, qw; the core normalizes it)
形の登録簿shape registry3D のワールドが持つ形の中身の表（snapshot の画像は番号で指す） / the 3D world's table of shape contents (snapshot images refer to it by index)
送る状態（transfer）transfer3D で別のピアに送る状態。full の画像＋形の登録簿＋凸包の表 / the 3D state sent to another peer: full image + shape registry + hull table
セッションsession2 ピアの試合をまとめたもの（ターン制・リアルタイム） / a two-peer match (turn-based or real-time)
ピアpeer試合に参加する 1 台 / one participant device
ホストhostピア 0。desync の時に正とする側 / peer 0, the reference when a desync is found
ゲストguestピア 1 / peer 1
手番moverターン制で今入力を出すピア / the peer whose turn it is (turn-based)
ターン制turn-based交互に入力を出し、決めた所まで進めて照合する方式 / peers take turns; simulate, then compare
リアルタイム（ロールバック）real-time (rollback)毎 tick 入力を出し、相手の分は予測して進める方式 / inputs every tick, remote inputs predicted
確定confirmed両方の入力が届き、その入力で計算し終えた tick / a tick computed with both peers' real inputs
予測prediction届いていない相手の入力を仮に決めて進めること / running ahead with a guess of the remote input
予測の上限prediction window (N)予測して進めてよい最大の tick 数（既定 10） / max ticks run ahead on predictions (default 10)
ロールバックrollback予測が外れた時、前の状態に戻すこと / restoring an earlier state when a prediction was wrong
再計算re-simulationロールバックした後、今の tick まで計算し直すこと / simulating again up to the current tick after a rollback
照合hash check確定した状態のハッシュを相手と比べること / comparing confirmed state hashes with the other peer
設定の照合config checkつなぐ前に、2 つのピアの設定・ルール・形・凸包・キネマティックの表・コアのバージョンが同じかをタグで確かめること / checking before connecting, with a tag, that both peers use the same settings, rule, shapes, hulls, kinematic tables and core version
照合のタグconfig check tag設定の照合で比べる値（rt: 設定の照合の値、ターン制: 設定のハッシュ） / the value compared in the config check (rt: the config check value, turn-based: the setup hash)
タグの中身tag contentsタグを部分（version・config・rule・shapes・kinematic）ごとに分けたハッシュ。タグが合わない相手と送り合う / one hash per part (version, config, rule, shapes, kinematic), exchanged with a peer whose tag does not match
違う所differing partタグの中身のうち、相手と違った部分（diff_parts） / the parts whose hashes differ from the peer's (diff_parts)
ハッシュstate hash状態の 64 bit の指紋（FNV-1a） / a 64-bit fingerprint of the state (FNV-1a)
desyncdesync2 ピアの状態が食い違うこと / the two peers' states differ
再同期resyncdesync した時、ホストの状態をゲストに送って置き換えること / replacing the guest's state with the host's after a desync
再接続（つなぎ直し）rejoin落ちたプロセスが作り直したセッションで試合に戻ること / a restarted process rejoining the match
再起動restartアプリ（プロセス）をもう一度起動すること / starting the app (process) again
入力の遅延input delay入力を何 tick 後に入れるか（既定 0） / how many ticks later an input is applied (default 0)
入力遅延の自動調整automatic input delay往復時間から入力の遅延を決める機能（既定 OFF） / choosing the input delay from the round trip (off by default)
往復時間round trip time (RTT)パケットが行って返事が戻るまで / time for a packet and its reply
time synctime sync進みすぎた側が 1 フレーム休んでそろえること / the side that runs ahead waits a frame
snapshotsnapshotワールドの状態の写し（dyn = 動く状態だけ / full = 全部） / a copy of the world state (dyn = moving state / full = everything)
basebasedyn の snapshot が使う full の土台（コアが自動で取る） / the full image a dyn snapshot builds on (taken automatically)
snapshot のリングsnapshot ringロールバック用に直近 N+1 tick の snapshot を持つ輪 / the ring of the last N+1 snapshots used for rollback
キネマティックkinematic力で動かず、決めた動きで動くボディ / a body moved by a prescribed motion, not by forces
動く凹形状moving concave shapetick の関数で動くキネマティックの凹形状 / a kinematic concave shape whose pose is a function of the tick
キネマティックの表kinematic table動きを付けたボディの一覧（detphys_kinematic） / the list of bodies with motions (detphys_kinematic)
分割split (sub-tick)速い tick だけワールドを細かく分けて進めること / stepping the world in smaller pieces only on fast ticks
すり抜けtunneling速い物が当たらずに通り抜けること / a fast body passing through another without contact
挟まれcrushing (squeezing)動く形が物を床や壁へ押し付けて、めり込ませること / a moving shape pressing bodies into the floor or a wall
回転軸spin axis3D のキネマティックが回る軸（整数のベクトル。既定は y 軸） / the axis a 3D kinematic body turns around (integer vector; y by default)
回転台turntable回転軸のまわりに回る台（3D の FIXED ＋ spin） / a platform spinning around its axis (3D FIXED path with spin)
外接半径bounding radiusボディの原点から形のいちばん遠い点までの距離（分割の判断に使う） / distance from the body origin to the farthest point of its shapes (used to decide splitting)
縁・仕切りrim, divider回る台の上の物を止める壁 / walls that keep bodies on a spinning platform
止まりながら往復back and forth with holdsPINGPONG の両端で決めた tick だけ止まる動き / a PINGPONG motion that waits a set number of ticks at each end
bulletbullet速い物に付ける連続判定の印 / the continuous-collision flag for fast bodies
眠るsleep止まったボディを計算から外すこと / a resting body taken out of the solver
落ち着くsettle動くボディが全部眠ること / all dynamic bodies are asleep
トランスポートtransportデータグラムを運ぶ差し替えられる API / the pluggable interface that carries datagrams
待ち受け / つなぐlisten / connectUDP の 2 つの形 / the two UDP modes
ループバックloopback1 プロセスの中で 2 ピアをつなぐトランスポート / a transport joining two peers in one process
接続のインターフェースconnection interface (link)ルームを作る・ルームコードで入る・状態を見る、の層（detphys_link.h） / the layer for creating rooms, joining with room codes and watching the state
ルームコードroom codeゲストが打ってルームに入る 6 桁の数字（5 桁 + チェックディジット） / the six digits a guest types to join a room (five digits plus a check digit)
チェックディジットcheck digit打ち間違いを見つけるための最後の 1 桁（Damm の方法） / the last digit that catches typos (the Damm algorithm)
テスト用のロビーtest lobby (hub)1 プロセスの中でルームの流れを試すトランスポート / a transport that runs the room flow inside one process
リレーrelayNAT を越えられない時にデータグラムを中継するサーバー / a server that forwards datagrams when NAT traversal fails
経路path相手までのつながり方（直接 DIRECT・リレー RELAYED・同じプロセス LOCAL）。動きの DETPHYS_PATH_* も同じ言葉 / how the datagrams reach the other peer (DIRECT, RELAYED, LOCAL); also the motion DETPHYS_PATH_*
desync デバッガーdesync debuggerdesync した tick・ボディ・フィールドを示す道具 / the tool that pinpoints the diverging tick, body and field
記録recording (DNDR)tick ごとの状態の記録 / a per-tick state recording
バンドルbundle (DNDB)2 ピアの記録と報告をまとめたもの / both peers' recordings plus the report
報告report比べた結果（最初に desync した tick・原因など） / the comparison result (first diverging tick, cause, …)
フィールドfieldボディの値の 1 つ（2D は x・y・cos・sin・vx・vy・w、3D は x・y・z・qx〜qw・vx・vy・vz・wx〜wz） / one body value (2D: x, y, cos, sin, vx, vy, w; 3D: x, y, z, qx–qw, vx, vy, vz, wx–wz)
ULPULP浮動小数点の最小の刻み / unit in the last place of a float
深いハッシュdeep hashBox2D の中身（接触など）まで入れたハッシュ。3D の記録では Box3D の状態のハッシュ / a hash including Box2D internals (contacts, …); in 3D recordings, Box3D's state hash
ワーカーworkerstep を手伝うスレッド（既定 1） / a thread that helps the step (default 1)
サンプルsampleエンジンのサンプルのプロジェクト・シーン / a sample project or scene
基準のハッシュreference hashes基準のビルドで出した正しいハッシュの列。サンプルと試験はこれと比べる / the hash list produced by the reference build; samples and tests compare against it
ヘッドレスの対戦headless match画面を出さずに 2 つのプロセスでサンプルの対戦を回す試験（Unreal はコマンドレット -run=DetPhysVersus） / a sample match between two processes without a screen (Unreal: the commandlet -run=DetPhysVersus)
（予定）(planned)このバージョンに入っていないもの。入るバージョンはまだ決めていない / not included in this version; no version is promised yet
（確認中）(unverified)書いたが、コードや実機でまだ確かめていないこと / written but not yet verified against code or devices
