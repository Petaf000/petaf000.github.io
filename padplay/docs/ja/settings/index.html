PadPlay

API リファレンス

PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

設定項目(Inspector)

Host の Inspector と同じ順に並べています。

  • Max Players (Settings.Players.MaxPlayers, 既定値 4) — 参加できるスマホの数です(1〜64)。
  • Resume Hold Seconds (Settings.Players.ResumeHoldSeconds, 既定値 300) — 通信が切れた人の枠を取っておく秒数です。この間に同じスマホが戻れば同じ番号になり、過ぎると PlayerRemoved が呼ばれます。0 で取っておきません。
  • Accept New Players (Settings.Players.AcceptNewPlayers, 既定値 on) — オフにすると新しいスマホを断ります(戻る人は入れます)。host.AcceptNewPlayers と同じ値です。
  • Calibrate Yaw On Connect (Settings.Players.CalibrateYawOnConnect, 既定値 on) — 参加・復帰したときにスマホが向いている方向を正面にします。スマホの左右の基準は起動のたびに変わるためです。
  • Create Devices (Settings.Players.CreateDevices, 既定値 on) — プレイヤーごとに PadPlayPad(Gamepad)を作ります。オフにすると、AttitudeReceived などの生のイベントだけが届きます。
  • Keep Phones Across Play (Settings.Players.KeepPhonesAcrossPlay, 既定値 on) — エディターだけ。再生を止めてもスマホは待っていて、次の再生で QR を読み直さずに同じ番号に戻ります。ビルドしたゲームでは、起動のたびに QR が変わります。
  • Modules (Settings.Modules, 既定値 Touch, Attitude, Buttons, Video) — 使う機能です。外したモジュールの入力はホストが捨て、何も送りません。Preset で Touch only・Gyro controller・Second-screen controller を選べます。
  • Drag Threshold Mode (Settings.Touch.DragThresholdMode, 既定値 EventSystem) — ドラッグを始める距離の決め方です。EventSystem はマウスと同じ値、Pixels は Drag Threshold Px、PhoneMillimeters はスマホの画面の上の Drag Threshold Mm を使います。mm で決めると、画面の大きさによらず同じ指の動きでドラッグが始まります。
  • Drag Threshold Mm / Px (Settings.Touch.DragThresholdMm / DragThresholdPx, 既定値 1.5 mm / 10 px) — Drag Threshold Mode が PhoneMillimeters のときは Mm を、Pixels のときは Px を使います。
  • Raycast Only Player Screen (Settings.Touch.RaycastOnlyPlayerScreen, 既定値 on) — タッチをそのプレイヤーの画面の Raycaster にだけ当てます。オフなら全部の Raycaster のいちばん手前に当たります。
  • Stale Timeout Seconds (Settings.Touch.StaleTimeoutSeconds, 既定値 0) — データが途絶えた指を、この秒数がたったら離したものとして扱います。0 なら扱いません。アプリは止まっている指のデータを送らないので、ふつうは 0 のままにします。
  • Send Ui Events (Settings.Touch.SendUiEvents, 既定値 on) — タッチを uGUI のイベントとして送ります。オフにすると、TouchReceived だけが届きます。
  • Click Speed Seconds (Settings.Touch.ClickSpeedSeconds, 既定値 0.3) — ダブルタップとみなすタップの間隔の上限です。
  • Player Targets (Settings.Touch.PlayerTargets, 既定値 empty) — プレイヤーごとにタッチが当たる画面(カメラか Display と範囲)です。無い人は Display 1 の全体です。コードでは host.Touch.SetPlayerTarget。
  • Max Extrapolation Ms (Settings.Attitude.MaxExtrapolationMs, 既定値 150) — 姿勢が届かない間、角速度で先を予測する時間の上限です。長いほど Wi-Fi の切れ目を埋めますが、その間に手が止まると行き過ぎて戻ります。
  • Correction Ms (Settings.Attitude.CorrectionMs, 既定値 50) — 予測した姿勢と、新しく届いた姿勢の差を埋める時間です。0 にすると、すぐに新しい姿勢へ跳びます。
  • Delay Buffer Ms (Settings.Attitude.DelayBufferMs, 既定値 0) — 届いた姿勢の間を補間するために遅らせる時間です。0 なら常に最新の姿勢を使います。ふつうの揺れをならすなら 10〜20 にします。
  • Smoothing (Settings.Attitude.Smoothing, 既定値 0) — pad.attitude のなめらかさ(0〜0.99)です。大きいほど手ぶれが減り、遅れが増えます。
  • Full Style (Settings.Attitude.FullStyle, 既定値 KeepGravity) — Full のリセンターの決め方です。KeepGravity は持っている傾きを取り除き(重力は下のまま)、KeepDeviceAxes はスマホの軸をそのままカメラの軸にします。
  • Recenter Mode (Settings.Attitude.RecenterMode, 既定値 Yaw) — Recenter のボタンと隅の長押しでの合わせ方です。Yaw は左右の向きだけを、Full は今の姿勢全体を合わせます。
  • Allow Phone Recenter (Settings.Attitude.AllowPhoneRecenter, 既定値 on) — スマホの画面の左上の隅を 1 秒長押しして、正面を合わせられるようにします。オフにすると、ゲームのボタンとコードからしか合わせられません。
  • Layout (Settings.Buttons.Layout, 既定値 none (PadPlay Setup: stick, A, B)) — 全員のスマホに出すボタン配置です。空ならボタンは出ません。再生中に変えるとすぐ送り直します。
  • Allow Haptics (Settings.Buttons.AllowHaptics, 既定値 on) — オフにすると振動を送らず、続いている振動も止めます。
  • Haptic Strength Scale (Settings.Buttons.HapticStrengthScale, 既定値 1) — すべての振動の強さに掛ける倍率(0〜1)です。機種による差をならすのに使います。
  • Haptic Refresh Ms / Duration Ms / Min Change (Settings.Buttons.HapticRefreshMs …, 既定値 100 / 150 / 0.05) — 続ける振動の送り方です。Refresh Ms は送り直す間隔、Duration Ms は 1 回に送る長さです(Host が止まっても、スマホはこの時間がたつと止まります)。Min Change は、間隔を待たずにすぐ送る強さの変化の大きさです。
  • Codec (Settings.Video.Codec, 既定値 Auto) — Auto なら H.264 を使い、H.264 の復号が遅いスマホから求められたときは JPEG にします。H.264 のエンコーダーが無い環境(macOS・Linux・OpenGL)では、全員 JPEG です。
  • Adaptive Video / Min Kbps / Priority / Min Fps / Min Scale (Settings.Video.AdaptiveVideo …, 既定値 on / 300 / Quality / 30 / 0.5) — Wi-Fi に合わせて、ビットレート・fps・大きさを上げ下げします。Priority は Quality なら大きさを保って fps から、Smoothness なら fps を保って大きさから下げます。
  • Total Max Kbps (Settings.Video.TotalMaxKbps, 既定値 0) — 全員を合わせたビットレートの上限です。1 人あたりの上限は、これを人数で割った値です。0 なら上限はありません。
  • Jpeg Scale / Fps / Quality (Settings.Video.JpegScale …, 既定値 0.5 / 30 / 75) — JPEG のときの大きさ(View に対する割合)・fps・最初の画質です。
  • Pacing Mbps (Settings.Video.PacingMbps, 既定値 20) — 1 フレーム分のデータを分けて、この速さで少しずつ送ります。キーフレームで Wi-Fi があふれるのを防ぐためです。0 なら一度に送ります。
  • Max Playout Frames (Settings.Video.MaxPlayoutFrames, 既定値 2) — 届き方が乱れているときに、スマホがならすために待つフレーム数の上限です。乱れていなければ待ちません。0 なら常に待ちません。
  • Use Ltr Recovery (Settings.Video.UseLtrRecovery, 既定値 on) — 映像が落ちたとき、エンコーダーが対応していれば、キーフレームより小さな立て直し用のフレームで直します。
  • Prefer Readback (Settings.Video.PreferReadback, 既定値 off) — Direct3D 11 / 12 でも、毎フレーム CPU へ読み戻します。GPU の経路で映像がおかしいときの回避策で、その分遅くなります。
  • Auto Prefer Readback (Settings.Video.AutoPreferReadback, 既定値 on) — GPU の経路で映像が直ってはまた崩れる PC では、自動で読み戻しに切り替えます。切り替えはその実行の間ずっと続き(エディターでは Play ごとに戻ります)、理由は PadPlay Debug と報告に出ます。遊ぶ人には何も出ません。
  • Mode (Settings.Preview.Mode, 既定値 EditorOnly) — 各スマホの画面を Game ビューの Display 2・3… に出します。既定はエディターだけです。
  • Player Displays / Show Touches / Show Buttons / Overlay Opacity / Show Caption (Settings.Preview.PlayerDisplays …, 既定値 2, 3, 4, 5 / on / on / 0.6 / on) — プレイヤーごとの Display の番号(0 は出さない)と、指・ボタン・説明の重ね方です。
  • Port (Settings.Port, 既定値 7780) — 通信に使う UDP ポートです。ほかで使われていれば次の空いている番号を使い、その番号を QR に入れます。
  • Game Name (Settings.GameName, 既定値 empty (Product Name)) — スマホと QR コードの横に出すゲームの名前です。
  • Host Addresses (Settings.HostAddresses, 既定値 auto) — QR コードに入れる IP アドレスです。VPN や仮想のネットワーク アダプターがある PC で、Wi-Fi のアドレスを先にするときに入れます。
  • Loopback Only (Settings.LoopbackOnly, 既定値 off) — 127.0.0.1 だけで待ち受けます(テスト用)。スマホはつながらず、Windows の確認画面も出ません。
  • Announce On LAN (Settings.AnnounceOnLan, 既定値 on) — 動いている間、この PC の Wi-Fi / LAN に「PadPlay のゲームがここにある」と知らせます(送るだけ)。つながらないスマホはこれを聞いて、止めているのが PC か Wi-Fi かを見分けます。送るのは、QR のトークンから作った名前(これでは参加できません)・ポート・PC のアドレスだけです。
  • Verbose Log (Settings.VerboseLog, 既定値 off) — 参加・退出・ボタン配置・映像の流れと、参加用の URL を Console に出します。
  • Display Language (Settings.DisplayLanguage, 既定値 Auto) — 遊ぶ人に見せる文(QR の下の文・Status View・Debug Overlay の報告の行)の言語です。Auto なら、OS が日本語のときは日本語、それ以外は英語です。エディターの表示言語とは別に決まります。
  • Show Connection Hints (Settings.ShowConnectionHints, 既定値 on) — この PC がスマホを止めているとき、QR コードの下に 1 行の案内とボタンを出し、スマホのアプリにも伝えます。そのため、QR を出したときに PC の設定を自分で調べます(約 5 秒、別のスレッドで)。オフにしても、CheckPcAsync などの API は使えます。
