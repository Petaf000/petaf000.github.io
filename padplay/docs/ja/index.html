PadPlay SDK ドキュメント

English

PadPlay SDK は、スマホを Unity のゲームの第二画面つきコントローラーにします。タッチパネル・ジャイロ・画面のボタン・振動に加えて、スマホごとにゲームの画面を出せます。まずはクイックスタートから読み、調べたいことが出てきたらこのページに戻ってください。

このドキュメントはパッケージの中(Packages/dev.petaf.padplay/Documentation~/ja)と、Web のpetaf.dev/padplay/docs/ja にあります。エディタでは Window → PadPlay → Welcome(パッケージを入れた後に 1 回だけ自動で開きます)で、最初の手順を確認し、1 クリックでサンプルを入れ、このドキュメントを開けます。メニューの道筋は英語の表示で書いています。Unity エディタを日本語にしている場合の読み替えは、クイックスタート の最初にまとめています。

必要なもの: 遊ぶ人それぞれのスマホに、別途 PadPlay アプリが要ります。また、PC とスマホを同じ Wi-Fi / LAN につなぐ必要があります(インターネット越しには遊べません)。必要な環境と動作を確かめた環境は クイックスタート §1 を見てください。

ページ

  • クイックスタート — 初めて PadPlay を組み込む時。インポート、Host の追加、スマホの接続、入力の読み取り、サンプル、トラブルシューティング。
  • 仕組み — 中で何が起きているかを知りたい時。プレイヤー枠、トークン、暗号化、状態と確実に届くメッセージ、タッチの流し込み、姿勢、映像、シーンの切り替え。
  • デバッグ — 入力が届かない時や、スマホごとに何が映っているかを見たい時。
  • Pose Camera — スマホを向けた方向を見回したい時。PC はスマホの向きで描き、描いた後に回った分はスマホが画面の上で補正します。
  • Remote Pointers — 遊ぶ人がスマホを画面に向けてカーソルを動かし、A で UI を押せるようにしたい時。
  • API リファレンス — 型・プロパティ・メソッド・イベントを調べる時。
  • 用語集 / Glossary — エディタを日本語で使っていて(Preferences → PadPlay)、英語の用語との対応を知りたい時。
  • 変更履歴 — パッケージのフォルダの CHANGELOG.md(英語)。版ごとの変更点。

主な型

  • PadPlayHost — Add Component → PadPlay → Host。シーンに 1 つ。接続・プレイヤー・設定(host.Settings)を持ちます。Keep Across Scenes(シーンをまたいで保つ)をオンにすると、シーンを読み込んでもスマホがつながったままです。
  • PadPlayQrView、PadPlayStatusView — Raw Image に PadPlay → QR View、Text か TextMeshPro のテキストに Status View を付けます。
  • PadPlayPointerEventData — スマホのタッチの PointerEventData(PlayerSlot・FingerId・PhonePosition)。
  • PadPlayPad — スマホ 1 台ごとの Input System のデバイス(Gamepad + attitude・angularVelocity・custom14〜custom31)。
  • PadPlayGyroCamera、PadPlayGyroPointer — PadPlay → Gyro Camera / Gyro Pointer。
  • PadPlayPoseCamera — PadPlay → Pose Camera: スマホの向きに合わせて動くカメラ。映像の遅れはスマホが隠します。
  • PadPlayRemotePointers、PadPlayRemoteLayout — GameObject → PadPlay → Remote Pointers: プレイヤーごとに uGUI を押せるカーソルを出します。スマホ側のレイアウトも同梱しています。
  • PadPlayView — PadPlay → View: カメラや RenderTexture をスマホへ送ります。
  • PadPlayPhoneOverlay — PadPlay → Phone Overlay: uGUI の Text・TextMeshPro のテキスト・Image を、スマホが映像の上に、画面に固定して描きます。
  • PadPlayButtonLayout — Assets → Create → PadPlay → Button Layout(アセット → 作成 → PadPlay → Button Layout): スマホに出すボタンとスティック。
  • PadPlayRaycaster — PadPlay → Raycaster: 透明なピクセルを無視する GraphicRaycaster。
  • PadPlayDebugOverlay、host.Diagnostics — PadPlay → Debug Overlay(デバッグ表示)と、コードから読む診断情報。

各型のメンバーは API リファレンス にあります。

スマホのアプリ

遊ぶ人は無料の PadPlay アプリを Google Play(Android 7.0 以上)か、App Store(iPhone、iOS 15 以降)から入れます。アプリは 1 つで、PadPlay を使ったどのゲームにもつながります。PadPlay SDK(Lite 以外)には、パッケージの PhoneApp~ フォルダにアプリのソースも入っています。アプリを自分でビルドしたり、自分の名前とアイコンで公開したりできます。クイックスタート §5 を見てください。
