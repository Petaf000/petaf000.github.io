PadPlay

全体の流れ

スマホが参加してから離れるまでの流れです。段階を選ぶと、そこで届くイベントと API を表示します。

  1. QR コードを出す

    Host が待ち受けを始め、QR View が QR コードを出します。PC がスマホを止めていると分かったときは、QR の下に帯が出ます。

    • host.AutoStart
    • host.JoinUriChanged
    • host.ConnectionHint
    • PadPlayQrView
    • console

  2. 参加

    プレイヤーの枠が決まります。入力はまだ届きません。

    • host.PlayerJoined
    • host.GetPlayerState
    • joinready

  3. 準備完了

    入力が届き始め、パッドが使えます。キャラクターを出すのはここです。

    • host.PlayerReady
    • host.GetPad
    • two

  4. ボタン配置

    スマホにボタン配置を送ります。全員に同じなら Settings.Buttons.Layout、1 人だけ変えるなら SetLayout です。

    • Layout
    • host.SetLayout
    • PadPlayButtonLayout

  5. 入力

    タッチは uGUI のイベントとして、ボタンとジャイロは PadPlayPad として届きます。

    • PadPlayPointerEventData.PlayerSlot
    • pad.attitude
    • pad.GetButton
    • host.Recentered
    • lag

  6. 映像

    View がカメラの絵をそのプレイヤーのスマホへ送ります。Wi-Fi が弱いと自分で画質を下げ、崩れたらスマホが立て直しを頼みます。

    • PadPlayView.SourceCamera
    • PadPlayView.PlayerSlot
    • host.ConnectionQualityChanged
    • host.RequestVideoStats
    • lag

  7. 通信が切れる

    Wi-Fi が切れたときや、アプリが裏に回ったときです。枠とパッドは残ります。

    • host.PlayerLeft
    • pad.IsConnected
    • ResumeHoldSeconds

  8. 復帰

    Resume Hold Seconds(既定 300 秒)のうちに戻れば、同じ枠に戻ります。Resumed は true です。

    • host.PlayerJoined
    • host.PlayerReady

  9. 退出

    時間切れ(Expired)、アプリで「切る」か Kick(Bye)、Host の停止(Stopped)のどれかです。キャラクターを消すのはここです。

    • host.PlayerRemoved
    • host.Kick
    • leftremoved
