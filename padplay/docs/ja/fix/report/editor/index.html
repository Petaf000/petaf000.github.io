報告を送る・問い合わせる

PadPlay Debug の報告タブから送ります

  1. Window → PadPlay → PadPlay Debug の報告タブで「報告をまとめる」を押します。報告はクリップボードにコピーされ、プロジェクトの Logs/PadPlay に保存されます。
  2. 名前・フォルダ・参加のトークンと鍵・外のアドレス・ネットワークの名前は消してあり、最後の行に消した物の数が出ます。
  3. 公開してよい報告は「Issue を開く(公開)」を押します。github.com/Petaf000/PadPlay の不具合の報告のフォームが、照合の番号だけが入った形で開きます。報告のうち、公開してよい部分を貼って送ります。
  4. 公開したくない報告は「メール」を押します。petaf570@gmail.com 宛ての短い下書きがメールのアプリで開き、添える .zip が表示されます。
  5. どちらのボタンも、それだけでは何も送りません。同じ QR コードでつないだスマホの報告には同じ照合の番号が出るので、2 つの報告を突き合わせられます。
