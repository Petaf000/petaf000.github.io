Windows のファイアウォールがこのゲームを止めています

  1. QR コードの下の「ファイアウォールの設定」を押すと、Windows の「ファイアウォールによるアプリケーションの許可」の画面が開きます。
  2. 帯に出る案内のとおり、「設定の変更」を押し、このゲームの「プライベート」にチェックを入れて「OK」を押します。一覧に無いときは「別のアプリの許可...」でゲームの .exe を選びます。
  3. ゲームに戻ると、ゲームが自動で確かめ直します。帯が消えれば直っています(QR コードも作り直されます)。
  4. Unity エディターとビルドしたゲームは別のプログラムなので、それぞれに許可が要ります。エディターでは、PadPlay Debug の接続タブの「許可する…」でも規則を足せます(Windows の管理者の確認が出ます。エディターだけの機能です)。足した規則は、同じタブの「PadPlay が足したファイアウォールの規則」の一覧から消せます。
  5. 配布するゲームでは、インストールのときに規則を足しておけば、遊ぶ人はこの手間が要りません。Windows のビルドの横に、そのためのファイルが入った <ビルドのフォルダー>_PadPlayDistribution ができます。アンインストールの時に規則を消す行も入っています。
