ファイアウォールで、このゲームがまだ許可されていません

  1. Windows の確認画面が出ていれば、「許可」(Windows によっては「アクセスを許可する」)を押します。ほかのウィンドウの後ろに隠れていることがあります。
  2. 確認画面が出ていなければ(出ないこともあります)、QR コードの下の「ファイアウォールの設定」を押し、開いた画面でこのゲームの「プライベート」にチェックを入れます。押す所は帯に出ます。
  3. 確認画面で「キャンセル」を押されると、ブロックの規則ができてしまいます。前もって知らせるなら、PadPlayFirstPrompt で確認画面の前に 1 文を見せられます。
