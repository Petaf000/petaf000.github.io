PadPlay

Console に PadPlay の警告が出る

シーンに有効な PadPlay Host がありません

  1. QR View・Status View・Phone Overlay・Gyro Camera・Gyro Pointer・Debug Overlay・PadPlay View は、Host が無いと何もしません。QR コードも出ません。
  2. GameObject → PadPlay → PadPlay Setup で Host を置くか、置いてある Host を有効にします。
  3. 警告には、待っている部品が 3 つまで名前で出ます。部品が有効になってから 2 秒後に 1 回だけ調べるので、スクリプトが Start で Host を作るときは出ません。
  • PadPlayHost
  • host.AutoStart
