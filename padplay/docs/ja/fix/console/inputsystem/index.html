PadPlay

Console に PadPlay の警告が出る

Input System がオフです

  1. Active Input Handling が Input Manager (Old) なので、Input System で入力を読む物に何も届きません。PlayerInput・Gyro Camera・Gyro Pointer・Debug Overlay のキー・有効な Input Action です。
  2. Edit → Project Settings → Player → Other Settings → Active Input Handling を Input System Package (New) か Both にします。Unity が再起動します。
  3. タッチ(uGUI のイベント)は Old のままでも届くので、Host とタッチだけのシーンではこの警告は出ません。
