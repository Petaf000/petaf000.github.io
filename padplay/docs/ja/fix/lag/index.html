PadPlay

操作や映像が遅れる

どの区間で遅れているかを見ます

  1. PadPlay Debug の状態タブでプレイヤーを選ぶと、詳細の下に「区間ごとの遅れ」が出ます。値は最近数秒の中央値です。
  2. 入力は「スマホ → PC」と「PC → ゲーム」、映像は「符号化」「送信」「通信」「表示」に分かれます。入力は、スマホで押すか離すと測れます。
  3. 一番長い区間はオレンジの帯と ▲ で示され、その下の 1 行に直し方が出ます。
  4. 映像の「通信」と「表示」はスマホが測るので、新しい版のアプリが要ります。「通信」は、スマホが測った時間から「符号化」と「送信」を引いた目安です。
  5. エディターの QR でつないだスマホでは、上の帯にも「入力の遅れ: … ms」「映像の遅れ: … ms」と出ます。遊ぶ人とビルドしたゲームには出ません。
