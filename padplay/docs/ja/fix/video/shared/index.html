PadPlay

映像が黒い・乱れる・遅い

全員向けの映像は、同じエンコーダーを使う人の中でいちばん弱い回線に合わせます

  1. Player Slot が -1 の View は、回線が似ている間は 1 回だけエンコードします。1 人の Wi-Fi だけがずっと遅いと、その人とほかの人を別々のエンコーダーで作るので、ほかの人の画質は下がりません。
  2. エンコーダーの数の上限は Max Encoders Per View です(既定 2、最大 4)。増やすほど GPU の仕事が増えます。1 にすると全員が 1 つを使い、いちばん弱い回線に合わせます。
  3. 画質を確実に保つには、プレイヤーごとに View を分けます(Player Slot = 0, 1 …)。全員の合計は Total Max Kbps で抑えられます。
