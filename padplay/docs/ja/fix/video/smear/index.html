PadPlay

映像が黒い・乱れる・遅い

映像の崩れを立て直しています

  1. 新しい版のアプリは、数秒ごとに映した絵を PC の絵と比べ、合わなければキーフレームを頼んで直します。遊ぶ人には何も出ません。
  2. 直した回数は host.RequestVideoStats の PictureRecoveries と、PadPlay Debug の報告に出ます。
  3. 直してもすぐ崩れる PC では、SDK が自動で読み戻し(Prefer Readback と同じ、少し遅いが確実な道)に切り替えます。切り替えた理由は PadPlay Debug の映像の状態と報告に出ます。止めたいときは Host › Video › Auto Prefer Readback をオフにします。

  • AutoPreferReadback
