映像が出ない

  1. Host › Modules の Video にチェックが入っているか確かめます。Lite 版には映像がありません。
  2. PadPlay Debug の状態タブに「映像のモジュールはオンですが、このスマホに送る PadPlay View がありません。」と出ていれば、そのプレイヤーに送る View(Player Slot がその番号か -1)を置くか、無効になっている View を有効にします。
  3. Display 2 / 3 のプレビューでも黒いときは、カメラか RenderTexture を見直します。URP では Source Camera を Base カメラにします。
  4. host.VideoStatus で、映像の経路と、送れない理由が分かります。
