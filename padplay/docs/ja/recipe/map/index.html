PadPlay

プレイヤーごとの地図を手元に出す

プレイヤーごとに用意したカメラの絵を、その人のスマホにだけ送ります。

地図用のカメラをプレイヤーの人数分置く(Culling Mask は UI のレイヤーだけ)

その子に Canvas(Screen Space - Camera)と地図の UI を置く

カメラに Add Component → PadPlay → View を追加する

メインカメラの Culling Mask から UI のレイヤーを外す

using PadPlay;
using UnityEngine;
using UnityEngine.EventSystems;

// On a map UI element: a tap on the phone is an ordinary uGUI click.
public class MapPin : MonoBehaviour, IPointerClickHandler
{
    [SerializeField] PadPlayHost host;

    public void OnPointerClick(PointerEventData e)
    {
        if (e is PadPlayPointerEventData p)
            host.Pulse(p.PlayerSlot, 80);   // short buzz for whoever tapped
    }
}

スマホを 2 台つなぐと、それぞれに別の地図が出ます。テレビ側には地図は出ません。

  • PadPlayView.SourceCamera
  • PadPlayView.PlayerSlot
  • PadPlayView.UseAsTouchTarget
  • PadPlayPointerEventData.PlayerSlot
  • host.Pulse
  • 映像が黒い・乱れる
  • タップしても反応しない
