PadPlay

スマホをハンドルにする

横に持ったスマホの傾きを、-1〜1 のハンドルの値にします。

GameObject → PadPlay → PadPlay Setup

車の GameObject に、下のスクリプト PhoneWheel を追加する

ボタン配置に「Center」ボタンを 1 つ足す(Role を Recenter に)

using PadPlay;
using UnityEngine;

public class PhoneWheel : MonoBehaviour
{
    [SerializeField] PadPlayHost host;
    [SerializeField] int playerSlot = 0;            // P1
    [SerializeField] float fullLockDegrees = 90f;   // turn this far = full lock

    public float Steer { get; private set; }        // -1 left .. 1 right

    void Update()
    {
        PadPlayPad pad = host.GetPad(playerSlot);
        if (pad == null || !pad.IsConnected)
            return;

        // After a Full recenter the pose the player holds is "straight".
        Vector3 up = pad.attitude.ReadValue() * Vector3.up;
        Vector3 flat = Vector3.ProjectOnPlane(up, Vector3.forward);
        float angle = Vector3.SignedAngle(Vector3.up, flat, Vector3.forward);
        Steer = Mathf.Clamp(-angle / fullLockDegrees, -1f, 1f);   // clockwise = right
    }
}

スマホをハンドルのように横に持ち、Center を押します。右に回すと Steer がプラスになります。

  • pad.attitude
  • host.Recenter
  • RecenterMode
  • PadPlayButtonLayout.Element
  • 値が変わらない
  • まっすぐの位置がずれる
