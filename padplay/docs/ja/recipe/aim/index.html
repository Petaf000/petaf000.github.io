ジャイロで狙って撃つ

スマホを向けた先に照準を出し、A ボタンで撃ちます。

動画: ジャイロで狙って撃つ (2:32)

Add Component → PadPlay → Gyro Pointer を追加する

照準にする UI の Image を Reticle に入れる

下のスクリプト GyroShooter を同じ GameObject に追加する

using PadPlay;
using UnityEngine;

public class GyroShooter : MonoBehaviour
{
    [SerializeField] PadPlayHost host;
    [SerializeField] PadPlayGyroPointer pointer;
    [SerializeField] Camera cam;

    void Update()
    {
        PadPlayPad pad = host.GetPad(pointer.PlayerSlot);
        if (pad == null || !pointer.IsPointing)
            return;
        if (!pad.buttonSouth.wasPressedThisFrame)
            return;

        if (Physics.Raycast(pointer.GetRay(cam), out RaycastHit hit))
            host.Pulse(pointer.PlayerSlot, 80);   // hit: short buzz
    }
}

スマホの上の端を画面に向けると照準が動きます。ずれてきたら、スマホの画面の左上の隅を 1 秒長押しします。

  • PadPlayGyroPointer.GetRay
  • PadPlayGyroPointer.IsPointing
  • yaxis
  • host.Pulse
  • 照準がずれる
  • A ボタンが反応しない
