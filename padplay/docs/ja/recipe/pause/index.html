PadPlay

スマホが離れたらゲームを止める

遊ぶ人がスマホの画面を消したりホームに戻ったりしたら、ゲームを止めて PAUSE の画面を出し、戻ったら続けます。

Host の GameObject に Add Component → PadPlay → Away Pause を追加する

入力を直接読むスクリプトに、下の 1 行を足す(Time.timeScale では止まらないため)

using PadPlay;
using UnityEngine;

public class Shooter : MonoBehaviour
{
    [SerializeField] PadPlayHost host;

    void Update()
    {
        if (PadPlayAwayPause.IsAnyPaused)
            return;   // the pause screen is up: no shots, no timers

        PadPlayPad pad = host.GetPad(0);
        if (pad != null && pad.buttonSouth.wasPressedThisFrame)
            Shoot();
    }

    void Shoot()
    {
        // ...
    }
}

再生してスマホをつなぎ、スマホの画面を消すかホームに戻ると、ゲームの画面がぼけて PAUSE が出て止まります。アプリに戻ると消えて、続きから動きます。スマホが無ければ、仮想スマホの「アプリから離れる」と「ゲームに戻る」で試せます。

  • PadPlayAwayPause
  • PadPlayAwayPause.IsPaused
  • PadPlayAwayPause.PauseOnGlance
  • host.PlayerAway
  • host.GetPresence
  • 止まるまでに数秒かかる
