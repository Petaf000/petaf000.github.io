PadPlay

5 分ではじめる

空のプロジェクトから、スマホで動かすまでの手順です。

必要なもの

  • 遊ぶ人のスマホに無料の PadPlay アプリ(まもなく Google Play と App Store に出ます)
  • PC とスマホを同じ Wi-Fi に
  • Windows 10 / 11、Unity 2022.3.62f3 以降

  1. パッケージを入れる

    Window → Package Manager → My Assets → PadPlay SDK → Download → Import

    Welcome のウィンドウが開きます。Input System の警告が出たら「Set to Both…」を押し、エディターを再起動します。

  2. シーンに置く

    GameObject → PadPlay → PadPlay Setup

    Host・QR コード・プレイヤーの一覧・EventSystem がまとめて入ります。

  3. 再生する

    Game ビューの右下に QR コードが出ます。

    Windows の確認画面が出たら、「許可」を押します(Windows によっては「アクセスを許可する」)。

    QR コードの下に帯が出たら、その文のとおりにボタンを押します。

  4. スマホをつなぐ

    PadPlay アプリで QR コードを読み、「つなぐ」を押します。

    スマホにスティックと A・B のボタンが出ます。スマホの画面から、ゲームの UI も押せます。

  5. 入力を読む

    下のスクリプトを GameObject に追加します。A を押すと Console に出ます。

    using PadPlay;
using UnityEngine;

public class PadReader : MonoBehaviour
{
    [SerializeField] PadPlayHost host;

    void Update()
    {
        PadPlayPad pad = host.GetPad(0);   // P1, or null
        if (pad == null || !pad.IsConnected)
            return;
        if (pad.buttonSouth.wasPressedThisFrame)
            Debug.Log("A pressed");
        transform.rotation = pad.attitude.ReadValue();
    }
}
