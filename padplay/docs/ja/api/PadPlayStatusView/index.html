PadPlayStatusView

参加しているスマホの一覧を Text か TextMeshPro に書きます。1 人 1 行で、番号・機種・状態・最後の入力からの秒数・ping を出します。実機で試すときの確認用です。抜けた人の行も残り、同じ枠に誰かが戻ると書き換わります。

  • Target — 書き込む先の Text か TextMeshPro のテキストです。空なら、同じ GameObject に付いているものに書きます。
  • Rows — 各行の元になる値です(PlayerSlot・Model・Os・State・LeftReason・LastInputKind・LastInputHostMs)。一覧を自分の UI で表示するときに使います。
  • Refresh — Refresh は今すぐ書き直します(ふつうは Refresh Interval Seconds ごと)。BuildText は書く文(色つきのリッチテキスト)を返します。言語はホストの Display Language に従います。
