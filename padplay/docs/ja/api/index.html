API リファレンス

English

ゲームで使う型とメンバーです。全部名前空間 PadPlay にあります(using PadPlay;)。Inspector の説明(Tooltip)と XML コメント(IntelliSense)にも、同じことをもっと詳しく書いています。ガイド: クイックスタート、仕組み、デバッグ。

いくつかの型は、エンジンに依存しない Core のアセンブリにあります(AttitudeCalibrationMode、ClockSync、DeviceInfo、PadPlayPhoneOverlayItem、PadPlayNetworkSettings、PadPlayVideoCodecChoice)。これらも同じ名前空間 PadPlay にあります。

プレイヤーの番号は 0 から始まる枠 です(playerSlot 0 が画面の「P1」)。イベントはメインスレッドで出ます。

エラーと例外。 渡した値の誤りは、その場で例外を投げ、何も変えません: 無いオブジェクトには ArgumentNullException、枠ごとに何かを持つメソッド(SetLayout、SetPhoneOverlay、Touch.SetPlayerTarget)に負の枠を渡すと ArgumentOutOfRangeException、メソッドが受け付けない値(形の合わないオーバーレイの一覧、Yaw / Full 以外の正面合わせのモード)には ArgumentException。その時の状況だけで決まる呼び出しは、例外を投げません。ホストが止まっている、その枠に誰もいない、スマホが振動できない・映像が無い、といった時は、bool を返すメソッドは false を返し(Pulse、SetHaptics、Recenter、Kick、TryGet…)、ほかは null・None・0・空の一覧を返します(GetPad、GetClockSync、GetCapabilities、止まっている間の RenewToken)。自然な範囲がある数(強さ 0〜1、パルスの長さ)は範囲に収めます。PC の都合で失敗しうる呼び出しは StartHost() だけです。UDP のポートを 1 つも開けない時は InvalidOperationException を投げ、IsRunning は false のままです。自分のイベントハンドラーが投げた例外はログに出し、ホストは動き続けます。

PadPlayHost

Add Component → PadPlay → Host(または GameObject → PadPlay → PadPlay Setup)。シーンに 1 つ。

開始と QR コード

  • Settings — Inspector の全部の値(PadPlayHostSettings): Players、Modules、Touch、Attitude、Buttons、Video、Preview、Port、GameName、HostAddresses、LoopbackOnly、VerboseLog、DisplayLanguage。IsEnabled(module)、SetEnabled(module, on)、ApplyPreset(preset)。
  • AutoStart — Start で待ち受けを始めます(既定はオン)。オフなら自分で StartHost() を呼びます。
  • StartHost()、StopHost() — 開始 / 停止。止めると全部のスマホを切ります(PlayerLeft、その後に理由 stopped の PlayerRemoved)。
  • IsRunning、Port — 待ち受けているか。実際に使っている UDP ポート(止まっている時は 0)。
  • JoinUri、JoinUriChanged — QR コードの中の URL(止まっている時は null)と、それが変わった時のイベント。
  • RenewToken() — 新しいトークンと鍵(新しい QR コード)。参加済みのスマホはそのままです。新しい JoinUri を返します(止まっている間は null)。
  • AcceptNewPlayers — オフ: 新しいスマホを「満員」として断ります。切れたプレイヤーは戻れます。
  • KeepAcrossScenes — シーンを読み込んでもスマホをつないだままにします(仕組み)。
  • KeptHost(static)、ActiveHost — シーンをまたいで残す Host。実際に動いている Host(残す Host か、この Host)。
  • NetworkSettings — 接続の詳しい値(PadPlayNetworkSettings)。StartHost の時に読みます(例えば RenewGraceMs)。
  • SdkVersion、ProtocolVersion、NowMs(static) — パッケージの版、プロトコルの版、ホストの時計(ms)。

プレイヤー

  • PlayerJoined(PadPlayPlayer) — スマホが参加して枠を得た(Resumed = 戻ってきた)。まだ入力は流れていません。
  • PlayerReady(PadPlayPlayer) — 入力が流れ始めた。GetPad(slot) がそのパッドを返します。参加 1 回につき 1 回。
  • PlayerLeft(PadPlayPlayerLeft) — スマホが切れた(Reason)。理由が Bye か Stopped(PadPlayLeaveReason)でなければ、枠は Resume Hold Seconds の間取っておきます。
  • PlayerRemoved(PadPlayPlayerRemoved) — 枠が本当に空いた(Bye・Stopped・Expired)。プレイヤーのキャラクターはここで消してください。
  • PlayerCount、PlayerSlots — 参加しているスマホの数(再接続を待っている物は数えません)と、その枠(小さい順)。
  • TryGetPlayer(slot, out player) — 参加しているプレイヤー(PlayerSlot、Device、AppVersion、Resumed、Capabilities)。
  • GetPlayerState(slot) — Connecting・Ready・Reconnecting・Gone(PadPlayPlayerState)。
  • Kick(slot) — スマホを切ります(枠は取っておきません)。
  • GetPad(slot)、PadDevices — そのプレイヤーの PadPlayPad(無ければ null)。全部のパッド。
  • GetScreenRotation(slot)、ScreenRotationChanged — スマホの画面の回転(度)。
  • GetCapabilities(slot)、GetClockSync(slot) — スマホのアプリが対応していること。時計のずれと往復の時間。
  • Diagnostics — 道具のための接続と入力のデータ(デバッグ §4)。

入力

  • Touch — タッチの振り分け: SetPlayerTarget(slot, camera) / (slot, display, rect)、ClearPlayerTarget(slot)、PhonePositionToPixel、GetDragThresholdPx(slot)。
  • Recenter(slot, mode = Yaw)、RecenterAll(mode) — プレイヤーの今の向きを正面にします。パッドと全部のジャイロの部品に効きます。
  • Recentered(PadPlayRecentered) — 誰がなぜ正面を合わせたか(Reason: Code、Button、LongPress、Connect)。
  • TouchReceived、AttitudeReceived、ButtonsReceived — 生のパケット。ふつうは uGUI のイベントと PadPlayPad で足ります。

スマホへの出力

  • SetLayout(slot, layout)、GetLayout(slot) — そのプレイヤーの画面のボタン(null = Settings.Buttons.Layout に戻す)。
  • SetHaptics(slot, strength) — 続けて振動させます。0〜1(0 で止まります)。pad.SetMotorSpeeds と同じです。
  • Pulse(slot, durationMs, strength = 1) — 決まった長さで 1 回振動させます。時間はスマホが計ります。
  • SetPhoneOverlay(slot, items)、GetPhoneOverlay(slot) — スマホが映像の上に描く文字と板(PadPlayPhoneOverlayItem。ふつうは PadPlayPhoneOverlay を通して使います)。

映像(PadPlay SDK のみ)

  • VideoStatus — 映像の送り方(グラフィックス API の経路、エンコーダー、プレイヤーごとのコーデック)、または H.264 を使わない理由。人が読むための文。
  • GetVideoChoice(slot, out choice) — そのプレイヤーが H.264 と JPEG のどちらか、その理由(Codec、Reason、Detail)。
  • RequestVideoStats(slot, callback) — 送信の統計(PadPlayVideoStats)。
  • TryGetPoseView(slot, out view) — Pose Camera のフレームについてスマホが知らせる値(動かしてから画面に出るまでの時間、補正)。

PadPlayPad

スマホ 1 台ごとの Input System のデバイスです。Gamepad そのもの なので、<Gamepad>/… のバインド、Gamepad.all、PlayerInput が動きます。

  • attitude、angularVelocity — QuaternionControl(校正後、Unity の座標系)、Vector3Control(rad/s)。パスは <PadPlayPad>/attitude、<PadPlayPad>/angularVelocity。
  • recenter — ButtonControl: プレイヤーが正面合わせを求めた(SDK はもう反映済み)。
  • GetButton(id) — PadPlayButtonId か番号でボタンを取ります。14〜31 はゲームが決めるボタン(<PadPlayPad>/custom14 … custom31)。
  • ButtonBits — 32 個のボタン全部をビットで。
  • PlayerSlot、IsConnected — プレイヤー。スマホが再接続を待っている間は false。
  • Recenter(mode = Yaw) — host.Recenter(PlayerSlot) と同じです。
  • SetMotorSpeeds(low, high) — 振動(強さ = 大きいほうの値)。PauseHaptics、ResumeHaptics、ResetHaptics もいつもどおり使えます。

タッチ

PadPlayPointerEventData(PointerEventData の一種): PlayerSlot、FingerId、PhonePosition(スマホの上の 0〜1、y = 0 が上)、ViewPoseSeq(プレイヤーが見ていた Pose Camera のフレーム)。どの uGUI のハンドラーでも eventData is PadPlayPointerEventData p で調べられます。

PadPlayRaycaster: 透明なピクセルを無視する GraphicRaycaster(AlphaThreshold、既定 0.1)。

部品

PadPlayQrView

Raw Image に付ける。主なメンバー: Host、Caption(Text か TextMeshPro のテキスト)、Texture、ShownUri、Refresh()。

PadPlayStatusView

Text か TextMeshPro のテキストに付ける。主なメンバー: Host、Target(書き込む先。空 = 同じ GameObject の物)、Rows、TryGetRow(slot, out row)、BuildText()。

PadPlayView

主なメンバー: SourceCamera か SourceTexture、PlayerSlot(AllPlayers = -1、既定)、Width、Height、FrameRate、MaxBitrateKbps、MatchPhoneAspect、UseAsTouchTarget。PadPlay SDK のみ。

PadPlayGyroCamera

主なメンバー: PlayerSlot、Mode(Window、LookAround、Tilt)、Settings、Tilt、Rotation、BaseRotation、ResetForward()(このカメラだけ)。

PadPlayGyroPointer

主なメンバー: PlayerSlot、Settings、ViewportPosition(y = 0 が下)、IsPointing、GetScreenPosition()、GetRay(camera)、Reticle、ResetForward()(このポインターだけ)。

PadPlayPoseCamera

主なメンバー: PlayerSlot、FieldOfView、Settings、YawOffsetDegrees、VisibleViewportRect、VisiblePixelRect、ScreenPointToRay(eventData)、TryGetView(out view)、ResetForward()(このカメラだけ)。Pose Camera を参照。

PadPlayPhoneOverlay

主なメンバー: PlayerSlot(AllPlayers = -1)、HideInPicture、RefreshSeconds、Refresh()。

PadPlayRemotePointers

主なメンバー: Layout、TargetCamera、Settings、GetPointerId(slot)(static)、GetHovered(slot)、IsPressing(slot)、TryGetScreenPosition(slot, out pos)、TryGetPointer(slot, out pointer)、ShowRecenterHint(slot)。Remote Pointers を参照。

PadPlayDebugOverlay

主なメンバー: Host、Visible、ToggleKey、BuildText()。

ボタンのレイアウト

PadPlayButtonLayout(Assets → Create → PadPlay → Button Layout): Elements、Orientation(Landscape、Portrait、Auto)、コードから Elements を変えた後の MarkChanged()、Create(params Element[])。PadPlayButtonLayout.Element: Id(PadPlayButtonId)、Shape(Circle、Rect)、Center、Size(0〜1、(0, 0) が左上)、Label、Opacity、Group、Role(None、Recenter)、Style。PadPlayButtonStyle(スマホでの要素の見た目。空 = いつもの見た目): Image、PressedImage、KnobImage(Texture2D。PNG にして 1 回だけ送る)、CustomColors と Color・PressedColor・BorderColor・LabelColor、CustomSizes と BorderWidth・CornerRadius・LabelSize、IsEmpty。PadPlayRemoteLayout: 同梱のリモコンのレイアウト(Create()、ボタンの Id は Press、Back、Recenter、Menu、Minus、Plus)。

版

PadPlayEdition: IsLite、Name("PadPlay SDK" か "PadPlay Lite")、LiteMaxPlayers(1)、ClampMaxPlayers(requested)。
