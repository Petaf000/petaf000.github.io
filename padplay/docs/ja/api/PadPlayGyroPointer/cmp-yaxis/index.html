PadPlay

API リファレンス

PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

PadPlayGyroPointer

スマホをリモコンのように画面へ向けると、指した所が画面の上の点になります。照準や、画面のメニューを指すカーソルに使います。手首をひねっても点は動きません。

  • PlayerSlot — どのプレイヤーのスマホで指すかを、枠の番号で指定します。2 人以上なら、プレイヤーごとにこの部品を付けます。
  • ViewportPosition — 指している点です。ビューポートと同じ 0〜1 で、y = 0 が下です。(0.5, 0.5) が正面で、画面の端で止まります。
  • IsPointing — 直前の更新でスマホの向きを読めたかどうかです。枠に誰もいない、再接続を待っている、まだ姿勢が届いていない、のどれかのときは false です。false の間は、カーソルを薄くしたり押す操作を取り消したりします。
  • GetRay — camera から、指している点を通るレイを返します。3D のオブジェクトとの当たり判定に使います。
  • GetScreenPosition — 指している点をスクリーンのピクセル(左下が原点)で返します。
  • Reticle — 点についてくる UI です(任意)。親の RectTransform の中で、アンカーを点の位置に合わせて動かします。
  • ResetForward — このポインターだけ、今の向きを真ん中にします(Recenter Blend Ms かけて移ります)。プレイヤー全体を合わせ直すなら host.Recenter を使います。
  • Settings.Axis — スマホのどの方向で指すかを決めます。DeviceTop はカメラのある短い辺で指します(リモコンと同じで、寝かせても傾けても変わりません)。TopEdge は表示の上の辺、Back は背面です。Auto はリセンターのたびに、平らに持っていれば上の辺、立てていれば背面を選びます。
  • Settings.HorizontalRangeDegrees — 点を左右の端から端まで、上下の端から端まで動かすのに、スマホを振る角度です。小さいほど敏感です。
  • Settings.Reference — リセンターのときに何を真ん中にするかを決めます。Full は今指している方向(左右と上下)を真ん中にします。Yaw は左右だけを合わせ、高さは水平が真ん中になります。
  • Settings.Smoothing — 向きのなめらかさ(0〜0.99)と、合わせ直した後に前の点から移る時間(ms)です。ポインターは小さな揺れが目立つので、カメラより強めでもかまいません。
  • Settings.FollowPadRecenter — FollowPadRecenter がオンなら、プレイヤーのリセンターに合わせてこのポインターも合わせ直します。CalibrateOnConnect がオンなら、参加・復帰したときに合わせ直します。FollowScreenRotation がオンなら、スマホを横にしても、右へ振れば点が右へ動きます。
  • TryGetForward — シーンを変えても、点を同じ所に保つための API です。今のポインターの正面を TryGetForward で取っておき、次のシーンのポインターの最初のフレームより前に StartFrom で渡します。ForwardCount は正面が変わるたびに増えます。
