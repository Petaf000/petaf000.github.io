PadPlay

API リファレンス

PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

PadPlayDiagnostics

ホストが受け取ったものと送ったものの、読み取り専用の記録です(host.Diagnostics)。PadPlay Debug・Debug Overlay・報告はこれを読みます。ゲームの動きには影響しません。

  • LastJoinAttempt — ホストが始まってから最後に届いた参加の試みと、届いた数です。PadPlay Debug の接続タブの「最後の接続の試み」はこれです。
  • ButtonPressesReceived — スマホから届いたボタンの押下の数(Input System の手前で数える)と、ゲームが読めた押下の数です。比べると「届いているのにゲームに見えていない」が分かります。PadPlay Debug の状態タブの「なぜ?」の行はこれを使います。
  • Players — ホストが始まってから見たプレイヤーごとの記録です(抜けた人も)。入力の頻度(TouchRateHz・AttitudeRateHz・ButtonsRateHz)、最後の入力の時刻、今触れている指、最後の姿勢とボタン、回線の状態などです。
  • CopyEvents — イベントの記録(古い順、最大 512 件)を写します。参加・退出・ボタン配置・振動・断った参加(JoinRejected)・回線・映像・SDK が自分でしたこと(AutoAction)・PadPlay の警告とエラーが入ります。
