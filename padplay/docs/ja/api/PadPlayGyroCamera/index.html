PadPlay

API リファレンス

PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

PadPlayGyroCamera

スマホの向きに合わせてカメラを回します。このカメラを Source Camera にした PadPlay View で、絵を同じプレイヤーのスマホへ送ると、スマホを窓のようにかざして見回せます。通信の遅れは、スマホが表示の直前に絵を回して隠します。

  • PlayerSlot — どのプレイヤーのスマホでこのカメラを回すかを、枠の番号で指定します。2 人以上なら、カメラごとにこの部品を付けて番号を変えます。
  • View — このカメラの絵を送る PadPlay View です。空なら、このカメラを Source Camera にしている View を使います。
  • FieldOfView — スマホに見える範囲の縦の画角(度)です。小さくすると望遠のように大きく映ります。代入すると Settings.FieldOfView に書きます。
  • YawOffsetDegrees — スマホの向きに足す左右の回転(度、プラスが右)です。座ったままドラッグで後ろを見る、などに使います。この回転はスマホの補正では隠れません。
  • BaseRotation — 正面のときのカメラのローカルの回転です。Awake のときの localRotation が入ります。
  • ScreenPointToRay — タップした所を通るワールドのレイを返します。PadPlay のタッチなら、プレイヤーがそのとき見ていたフレームのカメラで計算するので、素早く回していてもずれません(直近 256 フレームを覚えています)。
  • ResetForward — このカメラだけ、スマホが今向いている方向を正面にします(左右だけ。重力は下のまま)。プレイヤー全体を合わせ直すなら host.Recenter を使います。
  • Settings.OverscanPercent — 遅れを隠している間、上下左右に余分に描く量(見える大きさに対する %)です。多いほど速い回転も隠せますが、見える部分のピクセルは減ります(10% なら描いた絵の 83%)。
  • Settings.PhoneCorrection — スマホに絵を回させて遅れを隠します。違いを比べたいときだけオフにします。
  • Settings.Predict — 角速度から、描く時点の向きを予測します。上限は Host の Attitude の Max Extrapolation Ms です。
  • Settings.Smoothing — 向きのなめらかさ(0〜0.99)です。絵がそのプレイヤーへ行かないカメラ(PC の画面のカメラなど)のときだけ効きます。遅れを隠している間は使いません。
  • Settings.RecenterOnConnect — RecenterOnConnect がオンなら、参加・復帰したときに正面を合わせます。FollowPadRecenter がオンなら、プレイヤーのリセンター(host.Recenter・Recenter のボタン・隅の長押し)に合わせて、このカメラも合わせ直します。FollowScreenRotation がオンなら、スマホを横にしたときの画面の回転に合わせます。
  • IsCorrectingDelay — スマホがこのカメラの遅れを隠しているかどうかです。このカメラが、同じプレイヤーに送る PadPlay View の Source Camera になっていれば true です。Inspector にも表示されます。
  • VisibleViewportRect — スマホに実際に見えている範囲(オーバースキャンの内側)です。スマホに見せたい UI はこの中に置きます。絵と一緒に動いてほしくない文字は Phone Overlay に置きます。
  • TryGetView — TryGetView は、スマホが今見せている絵の motion-to-photon の時間と補正を返します(host.TryGetPoseView(PlayerSlot) と同じ)。HasAttitude は姿勢が一度でも届いたかどうかで、届くまでカメラは回りません。
  • Step — カメラを 1 フレーム分回します。AutoUpdate がオン(既定)なら LateUpdate で呼ばれます。順番を自分で決めたいときだけオフにして呼びます。
