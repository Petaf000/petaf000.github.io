PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

PadPlayFirstPrompt

Windows でゲームが初めて待ち受けを始めると、Windows が通信を許可するかを聞いてくることがあります(いつもではありません)。そこでキャンセルされるとスマホはつながらないので、その前に遊ぶ人へ 1 文を見せるためのクラスです。PadPlay がこの文を自分から出すことはありません。インストーラーでファイアウォールの規則を足すゲームでは要りません。

  • IsNeededAsync — Windows のファイアウォールの規則を調べ(約 5 秒、別のスレッドで)、このゲームの規則がまだ無ければ true を返します。StartHost の前、たとえばタイトル画面で呼びます。例外は投げません。
  • GetText — 確認画面の前に見せる 1 文を返します。
  • MarkShown — 見せたことをこの PC に記録します(PlayerPrefs)。MayBeNeeded は Windows を調べずに答える簡易な判定で、Windows のビルドでまだ MarkShown を呼んでいなければ true です。
