ActiveHost

ActiveHost は実際に通信している Host(残している Host か、この Host 自身)です。この Host のメンバーへの呼び出しはどれもそちらに渡されるので、ActiveHost が要るのは、シーンより長く生きるオブジェクトから購読するときだけです。KeptHost はシーンをまたいで残している Host です。
