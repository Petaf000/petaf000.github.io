PadPlay

API リファレンス

PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

PadPlayPad

スマホ 1 台が Input System の Gamepad 1 つになります。<Gamepad>/… のバインドや PlayerInput がそのまま動きます。PlayerReady のときに作られ、PlayerRemoved のときに消えます。

  • attitude — 校正した後のスマホの姿勢(Unity の座標)です。縦に持って画面をこちらに向けたときが単位回転です。ReadValue() で Quaternion が取れ、<PadPlayPad>/attitude でバインドもできます。
  • angularVelocity — 角速度です。単位は rad/s で、軸はカメラのローカルの軸です。
  • IsConnected — 再接続を待っている間は false です。その間もパッドは残り、姿勢は最後の値のまま、ボタンは離した状態になります。
  • GetButton — ボタン配置の Id でボタンを取ります。0〜13 は Gamepad のボタン(0 = buttonSouth、8 = dpad.up)、14〜31 はゲームが決めるボタンです(<PadPlayPad>/custom14 … custom31)。
  • recenter — プレイヤーがリセンターを求めたことを表すボタンです。SDK はもう合わせているので、効果音や案内に使います。
  • RecenterCount — 姿勢を合わせ直した回数です。合わせ直した姿勢と同じ更新で変わるので、attitude で物を回すコードは、このフレームで合わせ直せば跳びません。
  • Recenter — host.Recenter(PlayerSlot, mode) と同じです。
  • SetMotorSpeeds — スマホを振動させます。スマホのモーターは 1 つなので、2 つの値のうち大きいほうが強さになります。0, 0 で止まります。PauseHaptics・ResumeHaptics・ResetHaptics もいつもどおり使えます。
  • PlayerSlot — 0 始まりの枠の番号です(画面に出すときは +1 します)。復帰しても変わりません。
  • ButtonBits — 押しているボタンを、ボタン配置の Id のビットで返します(14〜31 も入ります)。
