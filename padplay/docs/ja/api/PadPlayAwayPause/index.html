PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

PadPlayAwayPause

参加していたプレイヤーのスマホが離れた・切れた(ホストが同じスマホを待っている)間、ゲームの画面をぼかした絵の上に「PAUSE」と「スマホを繋げてください」を出してゲームを止め、全員が戻ったら消して続けます。SDK はこれを置いたシーンでしかゲームを止めません。Built-in と URP のどちらでも動きます。

  • PauseOnGlance — 目を離しただけ(通知の幕・アプリの「切断しますか」が上にある = Glance)でも止めます。オフ(既定)なら、Away とつながりが切れた時だけです。
  • IsPaused — 止めているか(IsAnyPaused はシーンのどれか 1 つでも)と、待っているプレイヤーの枠です。Time.timeScale で止まらない物(キーやほかのスマホのボタンを直接読む所、スケールしない時間)は、これを見て止めます。
  • Paused — 一時停止の画面が出た・消えた時に呼ばれます(Time.timeScale と音を止めた後・戻した後)。Video Player や自分の時計を止めるのに使います。
  • 設定 — Pause Time = Time.timeScale を 0 に(物理・アニメーション・Time.deltaTime)、Pause Audio = AudioListener.pause。どちらも戻す時は前の値です。Blur Background がオフなら暗い画面。Title・Message が空なら「PAUSE」「スマホを繋げてください」(英語は Paused・Please reconnect your phone)で、言語はホストの Display Language(Use Host Language をオフにすると Language。Auto は端末の言語)。日本語は、Font を決めなければ端末の日本語のフォントで描きます。
