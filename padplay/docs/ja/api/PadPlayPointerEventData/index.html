API リファレンス

PadPlay のすべての型・メンバー・設定項目をこのページにまとめています。名前や意味で絞り込めます。

PadPlayPointerEventData

スマホのタッチ(と PadPlayScreenPointer)が uGUI に渡すイベントのデータです。PointerEventData の一種なので、どのハンドラーでも eventData is PadPlayPointerEventData p で、誰が触ったかが分かります。

  • PlayerSlot — 触ったプレイヤーの、0 始まりの枠の番号です。
  • PhonePosition — スマホの画面の上の指の位置です。0〜1 で、y = 0 が上です。position は、これをタッチが当たる画面のピクセルに直した値です。
  • FingerId — そのスマホの中での指の番号(0〜31)です。PadPlayScreenPointer のイベントでは -1 です。
  • ViewPoseSeq — タップしたときにプレイヤーが見ていた Gyro Camera のフレームの番号です。gyroCamera.ScreenPointToRay(eventData) がこれを使います。
