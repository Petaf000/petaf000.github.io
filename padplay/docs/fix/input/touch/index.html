Touches don't hit the UI

  1. If PadPlay Debug's Status tab says "Touches arrive, but hit no UI" under the player, the rest of the line says why (no EventSystem, no Raycaster, Raycasters only on other screens). Why? tells you where to fix it.
  2. Check that Touch is ticked in Host › Modules and that Touch › Send Ui Events is on.
  3. A player with their own screen (camera) only touches that screen. Check Touch › Player Targets and the View's Use As Touch Target.
  4. If touches don't pass through transparent pixels, or the Console says "is not readable (Read/Write is off)", turn on Read/Write for the texture.
