Input doesn't arrive

Buttons don't reach the game

  1. Check that the phone shows buttons. A Host added by hand has no layout; set Buttons › Layout (PadPlay Setup adds a stick, A and B).
  2. GetPad returns null until PlayerReady.
  3. PadPlay Debug's Status tab names where the presses stop. "Buttons arrive, but this project does not use the Input System": set Project Settings › Player › Active Input Handling to Both or Input System Package (New).
  4. "…Gamepad, but no Input Action reads it": check that your actions are enabled and bound to the Gamepad. With PlayerInput, check that the phone's pad is paired to it.
