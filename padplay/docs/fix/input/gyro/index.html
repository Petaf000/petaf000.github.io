Attitude doesn't arrive

  1. Check that Attitude is ticked in Host › Modules.
  2. If the Status tab says "This phone's app said it cannot send the gyro", the phone has no gyro or the app cannot read it. Use host.GetCapabilities(slot) to offer another way to play.
  3. If it is only off-center, recenter.
