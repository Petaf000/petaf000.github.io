Windows Firewall has no rule for this game yet

  1. If Windows' prompt is showing, press Allow access. It may be hidden behind other windows.
  2. If there is no prompt (it does not always appear), press Firewall settings under the QR code and tick Private for this game in the page that opens. The strip says what to press.
  3. Pressing Cancel in that prompt adds a Block rule. To warn players beforehand, PadPlayFirstPrompt gives you one sentence to show before it.
