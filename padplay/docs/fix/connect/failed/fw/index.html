Phones cannot connect

Windows Firewall is blocking this game

  1. Press Firewall settings under the QR code. Windows' "Allow an app through firewall" page opens.
  2. As the strip says: press Change settings, tick Private for this game, then OK. If it isn't listed, use Allow another app… and choose the game's .exe.
  3. The game checks again when you come back. When the strip goes, it is fixed (the QR code is rebuilt too).
  4. The Unity Editor and your built game are separate programs, so each needs it. In the Editor, Allow it… in PadPlay Debug's Connection tab can also add the rule (Windows asks for administrator permission; Editor only). Rules it added are listed under "Firewall rules PadPlay added" in the same tab, where you can remove them.
  5. For a game you ship, add the rule at install time and players never see this. A Windows build gets <build folder>_PadPlayDistribution beside it with the files for that, including the line that removes the rule on uninstall.
