PadPlay

Input or video lags

Find the slow stage

  1. Select a player in PadPlay Debug's Status tab. Delay by stage appears under the details, as medians of the last few seconds.
  2. Input is split into phone → PC and PC → game, video into encode, send, network and show. Input is measured when you press or release something on the phone.
  3. The longest stage has an orange bar and ▲, and the line below says how to fix it.
  4. The phone measures network and show, so they need a newer app. Network is an estimate: the time the phone measured minus encode and send.
  5. A phone that joined with the Editor's QR code also shows "Input delay: … ms" and "Video delay: … ms" in the strip at the top. Players and built games never show it.
