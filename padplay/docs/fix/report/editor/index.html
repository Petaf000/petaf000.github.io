Send a report

Send it from PadPlay Debug's Report tab

  1. In Window → PadPlay → PadPlay Debug, open the Report tab and press Collect a report. It is copied to the clipboard and saved in the project's Logs/PadPlay folder.
  2. Names, folders, the join token and key, public addresses and network names are taken out; the last line counts what was removed.
  3. For a report that may be public, press Open an issue (public). The bug report form of github.com/Petaf000/PadPlay opens with only the session code filled in; paste the parts of the report you are fine to make public, and submit it.
  4. For a report you don't want public, press Email. Your mail app opens a short draft to petaf570@gmail.com, and the .zip to attach is shown.
  5. Neither button sends anything by itself. A phone that joined with the same QR code shows the same code in its report, so the two reports can be matched.
