Send a report

Save it with Debug Overlay's report key

  1. If the game has a Debug Overlay, press the report key (F9 by default) while it is shown (F3 toggles it). The report is saved and copied.
  2. It is saved in Documents/PadPlay Reports. Send it to the game's maker, not to Petaf.
  3. Sending the phone's report too (Report a problem → Copy in the app) makes the cause easier to find.
