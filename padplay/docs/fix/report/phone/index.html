Send a report

Send it with Report a problem in the app

  1. Tap Report a problem on the Couldn't connect screen, or in About and licenses.
  2. The phone model, how it connected and recent records are put together, and all of it is shown. No name, Wi-Fi name, location or device ID is in it; IP addresses keep at most their first three numbers, and the QR code's token and key are hidden.
  3. Send by email opens a mail to petaf570@gmail.com with the report number in the subject. You decide in the mail app whether to send it.
  4. To give it to the game's maker, tap Copy and paste it into your message.
  5. The report number comes from the QR code, so it equals the session code in the PC's report for the same QR code. The records are kept in memory only and go when the app closes.
