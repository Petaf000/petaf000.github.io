PadPlay 用語集(日本語 / English)

PadPlay のエディタの窓・Inspector・実行時の表示を日本語で出す時の用語です。言語は Welcome の窓の右上か Preferences → PadPlay で選べます(Auto = Unity エディタの言語)。遊ぶ人が見る文字(QR の下の案内・Status View)は PadPlayHost の Connection → Display Language(Auto = OS の言語)。

  • Inspector の項目の名前(Max Players・Drag Threshold Mode など)は、コードのフィールドの名前と同じ英語のままです。説明(Tooltip)だけが日本語になります。
  • メニューの道筋(Window → PadPlay → …・GameObject → PadPlay → PadPlay Setup)・Console のログ・例外・Debugger のイベントの記録は英語のままです(検索と問い合わせのため)。
  • ドキュメントには英語版と日本語版があります。日本語版はパッケージの Documentation~/ja(目次)と https://petaf.dev/padplay/docs/ja/ に、英語版は Documentation~ と https://petaf.dev/padplay/docs/ にあります。日本語版の用語は、この用語集に合わせています。
  • メニューの道筋は、ドキュメントでは「→」でつないで書きます(例: Window → PadPlay → Welcome)。
