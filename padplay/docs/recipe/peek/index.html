PadPlay

Use the phone like a zoom lens

The phone turns a camera whose picture it shows: hold it up to look around, hold A to zoom.

Video: Use the phone like a zoom lens (2:24)

Add a lens camera, then Add Component → PadPlay → View

On the same camera: Add Component → PadPlay → Gyro Camera

Add the ZoomLens script below to the same camera

using PadPlay;
using UnityEngine;

// Next to PadPlayGyroCamera: hold A on the phone to zoom in like a telescope.
public class ZoomLens : MonoBehaviour
{
    [SerializeField] PadPlayHost host;
    [SerializeField] PadPlayGyroCamera lens;
    [SerializeField] float wideDegrees = 60f;
    [SerializeField] float zoomDegrees = 15f;

    void Update()
    {
        PadPlayPad pad = host.GetPad(lens.PlayerSlot);
        bool zoom = pad != null && pad.IsConnected && pad.buttonSouth.isPressed;
        float target = zoom ? zoomDegrees : wideDegrees;
        lens.FieldOfView = Mathf.Lerp(lens.FieldOfView, target, 1f - Mathf.Exp(-10f * Time.deltaTime));
    }
}

When the Gyro Camera's Inspector says the phone hides the delay, you are set. Press Play and hold up the phone: it shows where it points, and zooms while A is held. The TV keeps showing the usual camera.

  • PadPlayGyroCamera.FieldOfView
  • PadPlayGyroCamera.IsCorrectingDelay
  • PadPlayGyroCamera.ScreenPointToRay
  • PadPlayGyroCamera.VisibleViewportRect
  • The picture is black or broken
  • Forward drifts
