PadPlayAwayPause

While a joined player's phone is away or disconnected (the host waits for the same phone), it pauses the game under a blurred picture of it with "Paused" and "Please reconnect your phone", and goes on when everyone is back. The SDK pauses a game only where this is placed. Works with Built-in and URP.

  • PauseOnGlance — Also pause for a glance (the notification shade or the app's own question over the game). Off (default): only Away and a dropped connection.
  • IsPaused — Whether it pauses now (IsAnyPaused: any of them) and the slots it waits for. Hold what Time.timeScale does not stop (input read directly, unscaled time) with it.
  • Paused — Called when the pause screen appears and goes (after time and audio were paused / given back). Use them for Video Players or your own timers.
  • 設定 — Pause Time = Time.timeScale 0 (physics, animation, Time.deltaTime); Pause Audio = AudioListener.pause. Both give back the earlier values. Blur Background off = a dark screen. Empty Title / Message = "Paused" / "Please reconnect your phone" (in Japanese, PAUSE and its Japanese message), in the host's Display Language, or Language with Use Host Language off (Auto = the system's). Japanese is drawn with a Japanese font of the system unless Font is set.
