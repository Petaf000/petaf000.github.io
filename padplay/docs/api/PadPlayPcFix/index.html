PadPlayPcFix

Opens Windows' own settings pages. Neither PadPlay nor the game changes a setting or asks for administrator permission; the player makes the change in the page. Call it only from a button the player pressed (the strip under the QR code uses it through host.FixConnectionHintAsync()).

  • OpenFirewallSettings — Opens Windows Defender Firewall's "Allow an app through firewall" page. Show GetFirewallSettingsSteps() with it. Check the PC again with host.CheckPcAsync() when the player comes back.
  • GetFirewallSettingsSteps — What to press in that page, two sentences for players. It names this game's .exe for the case it is not in the list yet.
  • OpenNetworkSettings — Opens Windows' Settings → Network & internet, where the player makes the Wi-Fi a Private network.
  • PadPlayPcFixResult — The result of FixConnectionHintAsync and the like. Opened: a Windows page was opened (the player makes the change). Done: the host was restarted. Cancelled: the administrator prompt was declined (Editor tools only). Failed: it could not be opened. NotSupported: not Windows.
