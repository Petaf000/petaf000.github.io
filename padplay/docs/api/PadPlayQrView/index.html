PadPlayQrView

Shows the QR code on a Raw Image and redraws it when the URL changes. In Play mode, when this PC is found to block phones, a strip with one line and a button appears under it (hidden while a phone is connected).

  • Caption — Optional Text or TextMeshPro text with the game name. Turn on Show Uri in the Inspector to show the URL too.
  • ShownHint — The hint in the strip now. The button is Firewall settings, Open settings or Retry, and calls host.FixConnectionHintAsync(). After Firewall settings, the strip says what to press in the page that opened.
  • Refresh — Redraws from the current JoinUri. Not usually needed: it redraws itself when the URL changes.
  • Texture — The QR texture shown now and the URL in it. null while stopped.
