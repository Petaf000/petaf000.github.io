PadPlayFirstPrompt

The first time a game listens on Windows, Windows may ask whether to allow it (not always). If the player cancels, phones cannot connect, so this gives you one sentence to show before that. PadPlay never shows it by itself. Not needed when your installer adds the firewall rule.

  • IsNeededAsync — Reads Windows' firewall rules (about 5 s, another thread) and returns true when this game has no rule yet. Call it before StartHost, for example on the title screen. Never throws.
  • GetText — The sentence to show before the prompt.
  • MarkShown — Remembers on this PC that it was shown (PlayerPrefs). MayBeNeeded is a quick guess without reading Windows: true in a Windows build that has not called MarkShown.
