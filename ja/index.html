ゲームと、ゲームを作る人のための道具を

ペタフ(Petaf)は個人の開発者です。いまは、遊ぶ人の手元のスマホを画面つきのコントローラーにする Unity の SDK「PadPlay」を作っています。

準備中のもの

PadPlay

準備中

スマホを、画面つきのコントローラーにする Unity の SDK。

  • いまのコードのままで

    スマホは Input System の標準のゲームパッドとして、タッチはふつうの uGUI のイベントとして届きます。

  • 一人ひとりに別の絵

    カメラの絵を、一人のスマホにだけ送れます。自分だけの地図や、望遠レンズになります。

  • 同じ Wi-Fi だけで

    遊ぶ人は PadPlay のアプリで QR コードを読むだけ。PC とスマホが直接やりとりするので、サーバーもアカウントも要りません。
